# 一级相变 / First-Order Phase Transition

**一级相变**是热力学相变中伴随熵突变和体积不连续跳变的相变类型，其特征为自由能的一阶导数（如熵、体积）在相变点不连续。在铁电和 CDW 材料中，一级相变常表现为温度滞回（hysteresis）和双稳态共存。

## 核心内容

### 特征
- **熵突变**：相变点处熵发生有限跳变，伴随潜热释放或吸收。
- **温度滞回**：升降温过程中相变温度不同，形成滞回回线。
- **相界共存**：相变过程中两相共存，存在相界（phase boundary）。
- **双势阱描述**：自由能曲线在相变点附近呈双势阱形态，两个极小值对应不同相。
