# 序参量 / Order Parameter

**序参量**是描述相变中对称性破缺程度的宏观物理量，在高温对称相中为零，在低温破缺相中非零。序参量的引入是 Landau 相变理论的核心，将复杂的微观相变归结为单个（或少数几个）宏观量的演化。

## 核心内容

### 常见序参量
- **铁电相变**：极化 P 为序参量。
- **铁磁相变**：磁化 M 为序参量。
- **CDW 相变**：电荷密度波振幅为序参量。
- **结构相变**：原子位移或晶格畸变为序参量。

### Landau 展开
自由能 F = F₀ + αη² + βη⁴ + ...，其中 η 为序参量。α 随温度变号驱动连续相变；β < 0 时为一级相变。

### 序参量耦合
- 在多铁体系中，极化 P 和磁化 M 作为序参量通过耦合项 α_PM PM 相互影响 [[../papers/lvUnconventionalHystereticTransition2022]]。
- 序参量耦合是多铁材料磁电耦合的微观基础。
