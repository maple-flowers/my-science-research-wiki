## 📅 年度综述
2006年的学术写作见证了**电子结构计算精度的体系化提升**与**低维关联材料机理的范式更新**。这一年的核心贡献在于将投影缀加波（PAW）方法从基态性质推向了激发态与光学响应的巅峰，确立了全频率依赖 GW 方法与线性光学纵向表达式的标准化框架。同时，在准二维材料领域，研究者利用能量分辨瓦尼尔函数（Wannier Function）成功解析了长期困扰领域的“金属性与公度 CDW 共存”谜题，提出了子晶格解耦的新物理图景。

### 核心里程碑与术语趋势
- **VASP-GW 模块的奠基**：Shishkin 与 Kresse 在 *PRB* 上实现了高效的全频率依赖 $G_0W_0$，利用谱表示与 Hilbert 变换技术将计算成本大幅降低，并明确了芯-价相互作用的 HF 处理是含 $d$ 电子体系收敛的关键。
- **PAW 光学性质的理论重构**：Gajdos 等人通过引入偶极矩修正项 $\mu_{ij}$，解决了非局域 PAW 势下横向动量算符失效的问题，使标准 PAW 势的光学计算精度达到全电子水平。
- **CDW 子晶格解耦机制**：Barnett 等人揭示了 2H-TaSe2 中“次近邻跃迁主导”的反常特征，利用子晶格自发解耦完美解释了为何公度 CDW 下费米面仍不打开能隙。
- **术语趋势**：频繁出现“Quasiparticle energy”、“Spectral representation”、“Sublattice decoupling”、“Dipole correction”、“Longitudinal vs. Transversal expression”、“Next-nearest-neighbor hopping”和“Core-valence interaction”等术语。

## 📝 Introduction
### From: [[../papers/shishkinImplementationPerformanceFrequencydependentGWmethod2006]]
- **研究背景 (Background)**：讨论了 DFT 在预测带隙上的系统性偏差，以及 GW 近似作为高精度激发态计算方法的地位。
- **问题意识**：强调了全频率依赖计算的高昂成本以及传统赝势在处理 $d$ 电子和芯-价相互作用时的局限。
- **核心术语**：
  - Quasiparticle energy / 准粒子能量
  - Fully frequency-dependent / 完全频率依赖
  - Efficiency-accuracy trade-off / 效率与精度的权衡
  - Core-valence interaction / 芯-价相互作用

### From: [[../papers/Barnett2006coexistence]]
- **研究背景**：回顾了 2H-TMDs 中 CDW 与金属性共存的长期争议，特别是 ARPES 观测到的无隙激发。
- **问题意识**：挑战传统 CDW 理论中“费米面必须打开能隙”的定式思维，寻找定性的物理物理解释。
- **核心术语**：
  - Gapless excitations / 无隙激发
  - Commensurate CDW / 公度电荷密度波
  - Traditional wisdom / 传统认知
  - Qualitative nature / 定性本质

## 📝 Methods
### From: [[../papers/gajdosLinearOpticalProperties2006]]
- **理论框架**：详述了基于 PAW 变换的长波极限（$q \to 0$）极化率矩阵推导，对比了纵向（位置算符）与横向（动量算符）表达式。
- **计算逻辑**：引入偶极矩修正项以补偿非局域势的影响，并展示了 DFPT 与空带求和法的一致性。
- **关键术语**：
  - Longitudinal expression / 纵向表达式
  - Dipole correction / 偶极矩修正
  - Local field effects / 局域场效应
  - Adler-Wiser formula / Adler-Wiser 公式

### From: [[../papers/Barnett2006coexistence]]
- **建模策略**：展示了“DFT → 瓦尼尔函数下折 (Downfolding) → 最小紧束缚模型”的工作流。
- **物理机制**：通过瓦尼尔函数的相位干涉（Phase interference）解释最近邻跃迁的抑制与次近邻跃迁的主导。
- **关键术语**：
  - Wannier functions / 瓦尼尔函数
  - Tight-binding model / 紧束缚模型
  - Phase (constructive/destructive) interference / 相位（相长/相消）干涉
  - Sublattice decoupling / 子晶格解耦

## 📝 Results & Discussion
### From: [[../papers/shishkinImplementationPerformanceFrequencydependentGWmethod2006]]
- **算法验证**：证明了谱表示法使 QP 位移的计算量仅为静态 GW 的两倍，提供了 Si、GaAs 等材料的收敛基准值。
- **机制解析**：明确了 PAW 球内 HF 近似在 $G-G'$ 大矢量极限下的物理合理性。
- **核心术语**：
  - Spectral representation / 谱表示
  - Hilbert transform / Hilbert 变换
  - Single-shot $G_0W_0$ / 单次 $G_0W_0$ 计算

### From: [[../papers/Barnett2006coexistence]]
- **结论呈现**：证实了 CDW 畸变只涉及三个子晶格中的两个，第三个保持无畸变且无隙，与 ARPES 谱高度吻合。
- **稳健性分析**：通过引入有限的最近邻耦合证明了无隙结论对模型微扰具有鲁棒性。
- **核心术语**：
  - Undistorted sublattice / 未畸变子晶格
  - Robustness / 稳健性
  - Quasiparticle gap / 准粒子能隙
