## 📅 年度综述
2002年的学术写作展现了从**纳米受限体系的局域结构解析**到**复杂固相转变动态建模**的多维深度。这一年的核心趋势是利用高能物理手段（如 PDF 漫散射）挑战传统晶体学的极限，以及将概率统计模型（如元胞自动机）应用于宏观工业过程的微观解释。

### 核心里程碑与术语趋势
- **无机电子化合物的结构确认**：Petkov 等人利用原子对分布函数 (PDF) 技术，首次为室温稳定的无机电子化合物 $\text{Cs}_x\text{Si}_{32}\text{O}_{64}$ 提供了直接的阳离子亚晶格排列证据。
- **固相转变的概率建模**：学术表达中开始引入元胞自动机 (CA) 来模拟低碳钢中的 $\gamma \to \alpha$ 相变，强调了扩散控制下的成核与生长动力学。
- **术语趋势**：频繁出现“Electride”、“Pair distribution function (PDF)”、“Localized structural distortions”、“Diffusion-controlled”和“Probabilistic fashion”等术语。

## 📝 Introduction
### From: [[../papers/petkovStructureIntercalatedCs2002]]
- **研究背景 (Background)**：描述了电子化合物作为“低密度关联电子气”在纳米孔道中受限的独特性。
- **问题意识**：传统布拉格衍射因缺乏长程有序而失效，如何通过漫散射提取出嵌入物种的精确坐标？
- **核心术语**：
  - Low-density correlated electron gas / 低密度关联电子气
  - Unequivocal structural evidence / 明确的结构证据
  - Intercalated inside nanoporous materials / 插层于纳米多孔材料

### From: [[../papers/Zhang2002b]]
- **背景与目的**：指出微观组织对钢材性能的决定性影响，强调了预测相变动力学的工业价值。
- **论证思路**：提出 CA 模型作为传统微分方程的替代方案，用于处理具有大量自由度的复杂系统。
- **核心术语**：
  - Diffusion-controlled process / 扩散控制过程
  - Microstructural evolution / 微观组织演演化
  - Nucleation and growth / 成核与生长

## 📝 Methods
### From: [[../papers/petkovStructureIntercalatedCs2002]]
- **表征策略**：详述了同步辐射 X 射线总散射与差分 PDF (Differential PDF) 的处理流程。
- **模型拟合**：采用排除法对多种化学态（原子、阳离子、阴离子）进行模型筛选。
- **关键术语**：
  - Pair distribution function (PDF) / 对分布函数
  - Diffuse scattering / 漫散射
  - Atomic ordering / 原子有序性

### From: [[../papers/Zhang2002b]]
- **算法构建**：定义了二维六方格点下的元胞属性与演化规则。
- **物理耦合**：将溶质扩散场、温度场与成核概率函数进行显式有限元集成。
- **关键术语**：
  - Cellular automaton (CA) / 元胞自动机
  - Probabilistic fashion / 概率方式
  - Explicit finite method / 显式有限法

## 📝 Results & Discussion
### From: [[../papers/petkovStructureIntercalatedCs2002]]
- **结论呈现**：证实了 $\text{Cs}^+$ 离子在沸石孔道内形成了短程有序的锯齿形链 (Zigzag chains)。
- **物理洞察**：通过库仑排斥原理解释了负载上限的结构根源。
- **核心术语**：
  - Short-range ordered / 短程有序
  - Confined species / 受限物种
  - Structural coherence / 结构相干性

### From: [[../papers/Zhang2002b]]
- **模拟验证**：展示了不同冷却速率下铁素体晶粒尺寸的演化，并与光学显微镜实验对比。
- **关键发现**：明确了溶质场扩散相对于热扩散在控制组织均匀性上的主导地位。
- **核心术语**：
  - Grain size / 晶粒尺寸
  - Cooling rate / 冷却速率
  - Solute diffusion / 溶质扩散
