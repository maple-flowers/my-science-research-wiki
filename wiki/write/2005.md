## 📅 年度综述
2005年的学术写作呈现出从**平衡态费米面拓扑的精密测量**到**非平衡态/非常规序参量物理定义**的演进。这一年的核心贡献在于利用互补的实验技术（如 2D-ACAR 与 ARPES）确立了低维电荷密度波（CDW）的费米面嵌套驱动机制，并由 Nicola Spaldin 等人正式开启了“磁电多铁性”研究的复兴，明确了铁磁与铁电在原子尺度的互斥律。此外，超临界流体的非均相微观模型也在光谱证据下得到了确立。

### 核心里程碑与术语趋势
- **多铁性研究的“复兴”**：Spaldin 和 Fiebig 在 *Science* 上综述了磁电多铁性，提出了“几何铁电性”等绕开 $d^0$ 规则的新路径。
- **CDW 裸费米面的直接观测**：利用正电子湮灭技术（2D-ACAR）绕过 CDW 能隙，首次观测到 RTe3 体系未重构的费米面，证实了嵌套矢量的理论预测。
- **超临界水的非均相斑块模型**：通过 X 射线拉曼散射（XRS）揭示了超临界水中“扭曲氢键斑块”与“类气相分子”的共存。
- **术语趋势**：频繁出现“Fermi surface nesting”、“Multiferroics”、“Magnetoelectric coupling”、“Geometric ferroelectricity”、“Heterogeneous patch model”和“Thermal lens effect”等术语。

## 📝 Introduction
### From: [[../papers/Laverock2005fermi]]
- **研究背景 (Background)**：讨论了低维金属中 CDW 基态的普遍性，以及费米面不稳定性（FS nesting）的核心驱动作用。
- **问题意识**：如何获取未被能隙重构的“裸”费米面拓扑，以提供嵌套机制的决定性证据？
- **核心术语**：
  - Fermi surface nesting / 费米面嵌套
  - Nesting vector / 嵌套矢量
  - Unreconstructed Fermi surface / 未重构的费米面

### From: [[../papers/spaldinRenaissanceMagnetoelectricMultiferroics2005]]
- **研究背景**：指出微电子器件对磁、电功能集成的需求，以及单相多铁性材料稀缺的现状。
- **问题意识**：系统阐述了传统铁电性（空 $d$ 轨道）与铁磁性（部分填充 $d$ 轨道）在微观机制上的排斥。
- **核心术语**：
  - Renaissance of multiferroics / 多铁性的复兴
  - Mutually exclusive mechanisms / 互斥机制
  - Magnetoelectric effect / 磁电效应

## 📝 Methods
### From: [[../papers/Laverock2005fermi]]
- **技术互补**：强调了 2D-ACAR 对 CDW 能隙不敏感的特性，使其成为观测高温相费米面拓扑的理想手段。
- **理论关联**：利用 LMTO 方法计算广义磁化率 $\chi(q)$ 来定量定位最不稳定波矢。
- **关键术语**：
  - 2D-ACAR (Positron annihilation) / 二维角关联正电子湮灭
  - Generalized susceptibility / 广义磁化率
  - Bilayer splitting / 双层劈裂

### From: [[../papers/Yarai2005optical]]
- **检测方案**：提出一种基于热透镜（Thermal lens）效应的光纤传感路线，利用水分子的本征近红外吸收。
- **信号提取**：采用泵浦-探测（Pump-probe）架构与锁相检测技术提取微弱的折射率扰动。
- **关键术语**：
  - Thermal lens detection / 热透镜检测
  - Pump-probe technique / 泵浦-探测技术
  - Absolute vs. Relative humidity / 绝对与相对湿度

## 📝 Results & Discussion
### From: [[../papers/Laverock2005fermi]]
- **结论呈现**：实验测得的嵌套矢量 $q = 0.28 a^*$ 与理论计算高度一致，确立了 FS 嵌套的驱动地位。
- **物理洞察**：揭示了 Te 层间的双层劈裂是导致非公度（Incommensurate）嵌套的关键。
- **核心术语**：
  - Excellent propensity for nesting / 极佳的嵌套倾向
  - Incommensurate CDW / 非公度电荷密度波

### From: [[../papers/wernetSpectroscopicCharacterizationMicroscopic2005]]
- **微观图景**：通过差谱分析得出超临界水中约 65% 的分子处于完整但扭曲的氢键环境中，形成“氢键小岛”。
- **模型验证**：结合 SAXS 空间相关长度，构建了 5-10 分子规模的非均相斑块模型。
- **核心术语**：
  - Heterogeneous structure / 非均相结构
  - Intact but distorted H-bonds / 完整但扭曲的氢键
  - Patch model / 斑块模型
