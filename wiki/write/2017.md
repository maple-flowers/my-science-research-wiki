## 📅 年度综述
2017年的学术写作聚焦于**二维铁电物理的本征性确证**与**多光子荧光探针的维度拓展**。这一年的核心贡献在于：理论上预言并实验确证了以 α-In₂Se₃ 为代表的 III₂-VI₃ 族本征二维铁电体，其独特的面内（IP）与面外（OOP）极化互锁（Intercorrelation）机制打破了传统二维体系中偶极子失稳的理论限制；在光子学领域，开发了基于 D-π-A 架构的超敏感溶剂致变色探针，首次观测到“双光子三重荧光”（Two-photon triple fluorescence），实现了对极性、黏度与温度的多参量协同传感。同时，双光子聚合（TPP）技术在亚纳秒激光器的工程化应用中取得突破，确立了商业化光刻胶（SU-8, AR-N 4340）在大纵横比微纳构筑中的性能边界。

### 核心里程碑与术语趋势
- **本征二维铁电体的家族化预言**：Ding 等人在 *Nature Communications* 上定义了 III₂-VI₃ 族范德华层状材料的铁电性，强调了面内/面外极化的同时翻转路径（Kinetic pathways），为范德华异质结的调控提供了新分支。
- **双光子三重荧光的物理机制**：H. 等人利用 2,5-二氰基二苯乙烯衍生物，揭示了 LE（局部激发态）、TICT（扭曲胞内电荷转移态）与 Exciplex（准分子复合物）在不同极性环境下的动态平衡。
- **机械化学法与绿色合成的融合**：Doroodmand 等人展示了在丙酮等绿色溶剂中电合成 Salen 基共轭聚合物的工艺，通过阳离子直径（K⁺ > Na⁺ > Li⁺）对导电性的调制，确立了高性能湿度传感的结构范式。
- **术语趋势**：频繁出现“Intrinsic out-of-plane and in-plane polarization”、“III2–VI3 compounds”、“Van der Waals ferroelectrics”、“Two-photon triple fluorescence”、“Twisted Intramolecular Charge Transfer (TICT)”、“Push-pull chromophore”、“Solvatochromism”、“Sub-nanosecond TPP”、“Photoinitiator dwell time”和“Green solvent synthesis”等术语。

## 📝 Introduction
### From: [[../papers/dingPredictionIntrinsicTwodimensional2017a]]
- **研究背景 (Background)**：回顾了 2D 材料家族的演进，指出单层范德华材料中同时具备面内与面外本征铁电性的稀缺性。
- **问题意识**：探讨在 III₂-VI₃ 化合物中，极化翻转的动力学路径（Kinetic pathways）是否可在可达到的电场强度下实现。
- **核心术语**：
  - Stable single-layer / 稳定单层
  - Intercorrelated polarization / 互锁极化
  - Kinetic pathways / 动力学路径
  - Integrated heterostructures / 集成异质结

### From: [[../papers/H2017fluorescence]]
- **研究背景**：讨论了生物成像中双光子荧光（TPF）探针的需求，强调了溶剂致变色探针在定量分析分析物（如脂质筏）方面的优势。
- **问题意识**：寻求一种具备大双光子截面（δ）、宽变色范围且能同时响应极性、黏度与温度的理想探针分子。
- **核心术语**：
  - Two-photon cross section (δ) / 双光子截面
  - D-π-A architecture / D-π-A 架构
  - Solvatochromic probes / 溶剂致变色探针
  - Push-pull chromophore / 推-拉电子发色团

### From: [[../papers/Kumar2017microstructuring]]
- **研究背景**：对比了飞秒激光与亚纳秒激光在 TPP 加工中的成本效益，指出商业化光刻胶在简化加工流程中的潜力。
- **问题意识**：通过实验优化激光功率、扫描速度与驻留时间，以实现亚微米级（~0.5 μm）的高纵横比三维构筑。
- **核心术语**：
  - Sub-nanosecond laser / 亚纳秒激光
  - Writing system / 写入系统
  - Aspect ratio / 纵横比
  - Resolution optimization / 分辨率优化

## 📝 Methods
### From: [[../papers/dingPredictionIntrinsicTwodimensional2017a]]
- **模拟策略**：采用第一性原理计算预测单层结构的稳定性，并模拟电场诱导下的偶极子重排过程。
- **关键术语**：
  - Kinetic pathway analysis / 动力学路径分析
  - Kinetic barrier / 动力学能垒
  - van der Waals 2D ferroelectric / 范德华二维铁电体

### From: [[../papers/Kumar2017microstructuring]]
- **加工工艺**：采用 532 nm 亚纳秒脉冲激光，配合 3% 含量的光引发剂（2,4-二乙基-9H-噻吨-9-酮），在负胶中实现双光子聚合。利用 AFM 非接触模式表征微线宽度的功率依赖性。
- **关键术语**：
  - Photoinitiator (PI) / 光引发剂
  - Pulse energy / 脉冲能量
  - Threshold pulse energy / 阈值脉冲能量
  - Dwell time / 驻留时间

### From: [[../papers/Doroodmand2017conjugated]]
- **制备与表征**：详述了丙酮溶剂中 Salen 聚合物的电合成路径，以及利用循环伏安法（CV）评估不同碱金属氢氧化物（LiOH, NaOH, KOH）对聚合物亲水性与电导率的影响。
- **关键术语**：
  - Electro-polymerization / 电解聚合
  - Solvent polarity / 溶剂极性
  - Ohmic potential / 欧姆电势
  - Real-sample analysis / 真实样本分析

## 📝 Results & Discussion
### From: [[../papers/dingPredictionIntrinsicTwodimensional2017a]]
- **物理发现**：预言了 III₂-VI₃ 体系中电场反转面外极化会同步诱导面内极化的旋转，开启了多轴信号操纵的新机遇。
- **核心术语**：
  - Intrinsic out-of-plane polarization / 本征面外极化
  - Multi-axial switching / 多轴切换

### From: [[../papers/H2017fluorescence]]
- **性能评估**：展示了 P1 分子在 DMSO 中发射红移至 641 nm 的极端行为，揭示了黏度增加如何抑制电荷转移并导致第三条荧光带（Exciplex）消失。
- **核心术语**：
  - Two-photon triple fluorescence / 双光子三重荧光
  - Twisted excited state / 扭曲激发态
  - Non-emissive state / 非辐射态

### From: [[../papers/Kumar2017microstructuring]]
- **工艺结论**：验证了线宽随激光功率增加的平方根标度律，证实了亚纳秒激光作为低成本飞秒替代方案在三维支架制造中的可行性。
- **核心术语**：
  - 3D pillar / 三维微柱
  - Theoretical fit / 理论拟合
  - Cost-effective alternative / 高性价比替代方案
