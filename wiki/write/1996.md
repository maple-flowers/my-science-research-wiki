## 📅 年度综述
1996年是**密度泛函理论 (DFT) 走向标准化与工程化**的里程碑年份。这一年的学术写作不仅确立了现代电子结构计算的“标准泛函”（PBE），还系统性地规范了高效自洽求解算法的逻辑框架。

### 核心里程碑与术语趋势
- **PBE 泛函的诞生**：Perdew 等人提出的 PBE 泛函以“奥卡姆剃刀”原则简化了 GGA 构造，确立了满足核心物理极限而非盲目拟合数据的建模哲学。
- **VASP 算法框架的确立**：Kresse 与 Furthmüller 系统总结了迭代对角化 (RMM-DIIS) 与电荷混合 (Pulay/Kerker) 算法，将计算效率提升至 $N^2 \ln N$ 量级，奠定了现代模拟软件的通用范式。
- **术语规范化**：大量使用“Parameter-free”、“Nonempirical”、“Self-consistency cycle (SC)”、“Residual minimization”和“Linear response”等术语。

## 📝 Introduction
### From: [[../papers/kresseEfficiencyAbinitioTotal1996a]]
- **研究背景 (Background)**：指出 90 年代初 Car-Parrinello 方法在处理金属体系（费米面突变）与大规模模拟（时间步长受限）时的瓶颈。
- **问题意识**：如何构建高效、稳健且通用的自洽循环（SC）框架，以克服直接最小化方法的效率缺陷？
- **核心术语**：
  - *Ab-initio* total energy calculations / 从头算总能计算
  - Plane-wave basis set / 平面波基组
  - Self-consistency cycle (SC) / 自洽循环
  - Adiabatic decoupling / 绝热解耦

### From: [[../papers/perdewGeneralizedGradientApproximation1996a]]
- **背景与困境**：批判 PW91 泛函虽然成功但推导过于冗长（Byzantine），且在线性响应等物理极限上存在缺陷。
- **论证逻辑**：提出“少即是多”的物理建模思想——只满足能量上最关键的物理约束。
- **核心术语**：
  - Generalized Gradient Approximation (GGA) / 广义梯度近似
  - Parameter-free (Nonempirical) / 无经验参数（非经验的）
  - Exchange-correlation functional / 交换-关联泛函
  - Linear response / 线性响应

## 📝 Methods
### From: [[../papers/kresseEfficiencyAbinitioTotal1996a]]
- **算法创新**：提出残差最小化方法 (RMM-DIIS) 以避免显式正交化开销，并结合 Kerker 预条件混合抑制电荷震荡 (Charge sloshing)。
- **物理处理**：对比了线性四面体法与展宽法在力计算中的一致性。
- **关键术语**：
  - RMM-DIIS (Residual Minimization Method) / 残差最小化法
  - Methfessel-Paxton smearing / MP 展宽
  - Charge density mixing / 电荷密度混合
  - Kerker preconditioning / Kerker 预条件

### From: [[../papers/perdewGeneralizedGradientApproximation1996a]]
- **构造方案**：从 Lieb-Oxford 界等 7 个核心物理条件出发，构造简洁的增强因子 $F_X(s)$ 解析式。
- **方法论术语**：
  - Enhancement factor / 增强因子
  - Lieb-Oxford bound / Lieb-Oxford 界
  - High-density scaling / 高密度标度
  - Slowly varying limit / 缓慢变化极限

## 📝 Results & Discussion
### From: [[../papers/kresseEfficiencyAbinitioTotal1996a]]
- **结论呈现**：通过液态 Ge 与 Pd 表面等基准测试，证明 SC 方法在效率上优于直接最小化法 3-5 倍。
- **讨论要点**：强调了对“力”的快速收敛修正对结构弛豫的重要性。

### From: [[../papers/perdewGeneralizedGradientApproximation1996a]]
- **精度验证**：通过 20 个小分子的原子化能测试，证明 PBE 在保持简洁性的同时，精度与复杂的 PW91 相当。
- **未来方向**：承认半局域 GGA 无法描述范德华力，为非局域泛函预留了空间。
