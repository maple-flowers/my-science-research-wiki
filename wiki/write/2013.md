## 📅 年度综述
2013年的学术写作见证了**二维过渡金属碳化物（MXenes）从“实验室发现”向“材料家族”的跨越式演进**，以及**三维生物制造技术在亚微米尺度上的精确控制**。这一年的核心贡献在于确立了 MXenes 的“电子计数规则”（Electron counting rule），解释了表面官能团（-F, -OH, -O）如何通过电荷注入调控能隙，并将其形象地定义为兼具金属导电性与亲水性的“导电粘土”（Conductive clays）。在二维半导体（TMDs）领域，研究重点转向了应力工程下的电子云重构，揭示了金属-硫族元素间 p-d 杂化轨道在高应变下的稳定性机制。同时，双光子聚合（2PP）技术被系统化地应用于制备预血管化（Prevascularized）组织支架，标志着纳米加工从“复杂结构展示”向“生物功能器件集成”的范式转变。

### 核心里程碑与术语趋势
- **MXene 家族的定义与系统化**：Naguib 等人在 *Advanced Materials* 25周年特稿中正式确立了 MXenes 的命名规范，并提出通过层间插层（Intercalation）实现大规模剥离（Delamination）的普适路径。
- **MXene 半导体特性的物理准则**：Khazaei 等人揭示了 Sc2C 等体系在官能团修饰下的能隙开启机制，建立了“最大氧化态-电子平衡”模型。
- **2PP 亚衍射极限加工的确立**：Gittard 等人系统总结了双光子聚合在组织工程中的分辨率标度律，确立了其在三维生物制造中的领军地位。
- **术语趋势**：频繁出现“Conductive clays”、“Electron counting rule”、“Selective etching (MAX to MXene)”、“Delamination & Intercalation”、“Two-photon polymerization (2PP)”、“Voxel resolution”、“Sub-diffraction limit”、“p-d hybridization”、“Mechanical anisotropy”、“Evanescent-field sensing”和“Concrete RH monitoring”等术语。

## 📝 Introduction
### From: [[../papers/naguib25thAnniversaryArticle2013a]]
- **研究背景 (Background)**：回顾了石墨烯引发的二维材料热潮，引出 MAX 相作为前驱体通过选择性蚀刻（Selective etching）制备 MXenes 的新路径。
- **问题意识**：强调 MXenes 兼具金属导电性与亲水表面的独特性，探讨其在能量存储与复合材料中的巨大潜力。
- **核心术语**：
  - Selective etching / 选择性蚀刻
  - MAX phases / MAX 相
  - Conductive clays / 导电粘土
  - Hydrophilicity / 亲水性

### From: [[../papers/Li2013bonding]]
- **研究背景**：指出 TMDs 在大弹性形变下的独特性，适合应力工程（Strain-engineered）与柔性电子学。
- **问题意识**：探讨不同化学成分（Mo vs. W）与负载方向（Armchair vs. Zigzag）如何决定二维材料的极限强度。
- **核心术语**：
  - Large elastic deformation / 大弹性形变
  - Strain-engineered devices / 应力工程器件
  - Ultimate strength / 极限强度
  - Flexible electronics / 柔性电子学

### From: [[../papers/Gittard2013polymerization]]
- **研究背景**：对比了细胞在 2D 与 3D 环境中的表型差异，引出 3D 支架（Scaffold）在组织工程中的必要性。
- **问题意识**：分析 2PP 如何突破衍射极限（Diffraction limit），实现与亚细胞细胞器同尺度的精确制造。
- **核心术语**：
  - Cell morphology / 细胞形态
  - Sub-micron resolution / 亚微米分辨率
  - Diffraction limit / 衍射极限
  - Tissue engineering scaffold / 组织工程支架

## 📝 Methods
### From: [[../papers/naguib25thAnniversaryArticle2013a]] & [[../papers/khazaeiNovelElectronicMagnetic2013]]
- **制备与模拟策略**：详细描述了室温下利用 HF 酸蚀刻 Al 层的工艺，以及利用 DMSO 等有机分子插层辅助剥离的方法。理论上强调了 HSE06 杂化泛函在预测窄带隙半导体时的准确性优于 PBE。
- **关键术语**：
  - HF etching / HF 蚀刻
  - Delamination / 剥离
  - Intercalation / 插层
  - Hybrid functional (HSE06) / 杂化泛函

### From: [[../papers/Li2013bonding]]
- **表征逻辑**：通过第一性原理计算（DFT）模拟不同载荷下的应力-应变响应，重点关注金属原子与硫族原子间电荷转移的动态分配。
- **关键术语**：
  - First-principles DFT / 第一性原理 DFT
  - Charge transfer (ΔQ) / 电荷转移
  - Stress-strain relation / 应力-应变关系
  - Mechanical anisotropy / 机械各向异性

### From: [[../papers/XiaokangZhang2013calibrating]]
- **传感设计**：设计了双包层单模纤维（DCSMF）结构，利用琼脂糖（Agarose）涂层的消逝场（Evanescent-field）效应实现湿度传感。
- **关键术语**：
  - Double-cladding single-mode fiber (DCSMF) / 双包层单模纤维
  - Evanescent-field / 消逝场
  - Real-time monitoring / 实时监测

## 📝 Results & Discussion
### From: [[../papers/naguib25thAnniversaryArticle2013a]]
- **性能评估**：展示了 MXene 纸的高电导率与优异的体积比电容（>330 F/cm³），并证明其作为燃料电池催化剂载体具有比碳载体更高的耐久性。
- **核心术语**：
  - Volumetric capacitance / 体积比电容
  - Cycle stability / 循环稳定性
  - Catalyst support / 催化剂载体

### From: [[../papers/khazaeiNovelElectronicMagnetic2013]]
- **物理发现**：提出了 Sc2C 在 OH 或 F 官能团修饰下转变为半导体的“电子中性”准则；揭示了 O 官能团因电子需求较高而更倾向于占据 B 型空位。
- **核心术语**：
  - Semiconducting MXene / 半导体 MXene
  - Functional group control / 官能团调控
  - Electronic neutrality / 电子中性

### From: [[../papers/Li2013bonding]]
- **结论呈现**：证实了 TMDs 的强度由金属 d 轨道与硫族 p 轨道的杂化（p-d hybridization）强度决定，且 W 基材料强度普遍高于 Mo 基。
- **核心术语**：
  - p-d hybridization / p-d 杂化
  - Orbital redistribution / 轨道重构
  - Compositional dependence / 成分依赖性

### From: [[../papers/Gittard2013polymerization]]
- **应用落地**：展示了利用 2PP 制造的预血管化网络支架（Prevascularized scaffold）以及用于伤口闭合的微型倒钩（Microscale barbs）。
- **核心术语**：
  - Prevascularized network / 预血管化网络
  - Microscale barbs / 微型倒钩
  - Regenerative medicine / 再生医学
