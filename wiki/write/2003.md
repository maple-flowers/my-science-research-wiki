## 📅 年度综述
2003 年的学术写作见证了**纳米尺度物理极限的静电学定义**、**介观尺度相变动力学的物理建模**与**有机/无机杂化体系构效关系的系统化**。这一年的核心贡献在于：利用第一性原理超胞计算确立了铁电薄膜的“临界厚度”概念，打破了以往假设完美屏蔽电极下铁电性始终存在的幻象，将退极化场确立为支配超薄铁电行为的关键因素；同时，在计算材料学领域，通过将局部溶质浓度显式耦合到元胞自动机规则中，实现了从“冷却速率”到“最终晶粒尺寸”因果链的定量描述，减少了对经验参数的依赖；在有机导电领域，研究者揭示了配体效应如何通过改变中心金属价态，进而利用库仑散射机制主导载流子的传输行为。

### 核心里程碑与术语趋势
- **铁电性临界厚度的确立**：Junquera 和 Ghosez 在 *Nature* 上发表论文，证明了由于真实电极的有限屏蔽长度，BaTiO3 在 6 个晶胞（约 24 Å）以下会因退极化场而失去铁电稳定性。
- **元胞自动机 (CA) 物理化**：学术表达中开始强调将局部溶质浓度（如碳扩散场）与 CA 概率规则显式耦合，利用 Stefan 条件描述界面移动。
- **构效关系的分子工程化**：明确了“配体电子诱导效应—金属混合价态—库仑散射强度—电导率”的链条式论证逻辑。
- **术语趋势**：频繁出现 "Critical thickness"、"Depolarizing field"、"Screening length"、"Short-circuit boundary conditions"、"Cellular automaton (CA)"、"Soft-impingement"、"Mixed-valence copper(II/I)"、"Coulomb scattering"、"Vibronic-coupling" 和 "Electron inductive effect"。

## 📝 Introduction
### From: [[../papers/junqueraCriticalThicknessFerroelectricity2003]]
- **研究背景 (Background)**：讨论了微电子器件微缩化进程中，铁电性是否具有物理下限的长期争论。
- **问题意识 (Problem Statement)**：批判了以往假设“完美屏蔽电极”的理论模型，提出必须考虑真实金属界面有限屏蔽长度导致的退极化场。
- **核心术语**：
  - Miniature electronic devices / 微型电子器件
  - Electrostatic limit / 静电学极限
  - Perfect screening assumption / 完美屏蔽假设
  - Depolarizing field / 退极化场 (去极化场)
  - Ferroelectric instability / 铁电不稳定性

### From: [[../papers/Zhang2003a]]
- **研究背景**：指出低碳钢相变模拟中现有方法使用过多可调参数，难以清晰区分冷却条件的影响。
- **问题意识**：探讨如何建立物理基础更清晰的模型，定量揭示冷却速率通过“形核-生长竞争”决定微观组织的规律。
- **核心术语**：
  - Solid-state phase transformation / 固态相变
  - Nucleation and growth / 形核与生长
  - Driving force / 驱动力 (过冷度 ΔT)
  - Competitive mechanism / 竞争机制

### From: [[../papers/Unknown2003charge]]
- **研究背景**：回顾了 BEDT-TTF 作为有机导体的潜力，指出合成条件（特别是金属受体还原程度）对导电性的剧烈影响。
- **问题意识**：探究为何不同卤素配体会导致完全不同的铜价态和电荷传输行为？
- **核心术语**：
  - Charge transfer (CT) compounds / 电荷转移化合物
  - Organic conductors / 有机导体
  - Ionization state / 离子化状态 (BEDT-TTF radical cation)
  - Structure–property relationship / 构效关系

## 📝 Methods
### From: [[../papers/junqueraCriticalThicknessFerroelectricity2003]]
- **建模策略**：显式构建“电极/薄膜/电极/衬底”完整超胞，利用周期性边界条件自然施加短路（Short-circuit）边界。
- **表征手段**：结合 Berry 相方法计算极化，通过能量-软模位移曲线判断铁电稳定性。
- **关键术语**：
  - Supercell technique / 超胞技术
  - Short-circuit boundary condition / 短路边界条件
  - Berry-phase calculation / Berry 相计算
  - Soft-mode distortion / 软模畸变
  - Numerical atomic orbital / 数值原子轨道 (SIESTA 代码)

### From: [[../papers/Zhang2003a]]
- **算法改进**：提出一种将局部溶质浓度变化耦合到 CA 概率规则中的新方法，减少了对经验参数的依赖。
- **物理简化**：采用“超元素 (Super-element)”近似处理多组分钢材，通过显式有限体积法求解扩散方程。
- **关键术语**：
  - Cellular automaton (CA) / 元胞自动机
  - Probabilistic rules / 概率规则
  - Super-element approximation / 超元素近似
  - Solute redistribution / 溶质再分配 (排出)
  - Soft-impingement / 软碰撞 (扩散场重叠)

### From: [[../papers/Unknown2003charge]]
- **表征体系**：综合利用红外 (IR) 的 vibronic 耦合指纹判断分子离子化，利用 EPR 和 SQUID 探测金属混合价态。
- **关键术语**：
  - Vibronic-coupling bands / 振动电子耦合带 (A1g 指纹)
  - Hyperfine splitting / 超精细分裂 (EPR)
  - Curie-Weiss law / 居里-外斯定律
  - Cyclic voltammetry (CV) / 循环伏安法

## 📝 Results & Discussion
### From: [[../papers/junqueraCriticalThicknessFerroelectricity2003]]
- **结论呈现**：证实了约 24 Å 的临界厚度，低于此值则退极化场压制铁电性；即使在临界厚度以上，极化强度仍低于体相值。
- **机制解析**：通过宏观静电模型 $E = U - P \cdot E_d$ 定量复现第一性原理结果，证明静电学而非界面键合是主导因素。
- **核心术语**：
  - Finite critical thickness / 有限临界厚度
  - Electrostatic energy / 静电能量
  - Interface dipole / 界面偶极子
  - Depolarization-field-induced suppression / 退极化场诱导的压制

### From: [[../papers/Zhang2003a]]
- **动力学揭示**：定量显示高冷却速率通过增加早期过冷度来提高形核率，从而获得细小晶粒。
- **机制解析**：通过转变分数曲线可视化形核与生长的动态竞争，确认形核主要在过冷早期阶段完成。
- **核心术语**：
  - Nucleation-dominated / 形核主导
  - Grain refinement / 晶粒细化
  - Equiaxed growth / 等轴生长
  - Transformation kinetics / 相变动力学

### From: [[../papers/Unknown2003charge]]
- **磁电关联**：证实残留的 Cu(II) 局域 d 电子是导电电子的强散射中心。
- **化学机制**：阐述了 Br⁻ 的电子诱导效应更弱，导致其残留 Cu(II) 更多，进而通过库仑散射导致更低的电导率。
- **核心术语**：
  - Mixed-valence state / 混合价态
  - Coulomb scattering / 库仑散射
  - Electron inductive effect / 电子诱导效应
  - Localized magnetic center / 局域磁性中心
