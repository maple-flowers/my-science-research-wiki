## 📅 年度综述
1984年是**分子动力学 (MD) 统计力学基础**确立的关键年份。这一年的核心贡献在于解决了如何在微正则系综（NVE）框架下严格模拟正则系综（NVT）和恒温恒压系综（NPT）的理论难题。此外，这一年还在**有机电荷转移盐 (BEDT-TTF)** 的合成与**电荷密度波 (CDW)** 的拉曼光谱理论方面有重要进展。

### 核心里程碑与术语趋势
- **扩展系统方法 (Extended System Method)**：Shuichi Nosé 提出的扩展系统概念，通过引入额外自由度 $s$ 将控温机制建立在严格的哈密顿力学之上，彻底改变了以往依赖经验标度的局面。
- **有机超导体基础**：BEDT-TTF（二乙烯二硫杂萘四硫富瓦烯）供体的合成与电化学制备趋于成熟，为后续发现有机超导体奠定了物质基础。
- **术语趋势**：大量使用“Canonical ensemble”、“Thermostat”、“Extended system”、“Charge transfer complex”、“BEDT-TTF”和“Raman spectra”等词汇。

## 📝 Introduction
### From: [[../papers/noseUnifiedFormulationConstant1984]]
- **研究背景 (Background)**：指出当时存在多种相互竞争的控温方法（如 Anderson 随机碰撞、动量标度），但缺乏统一且严格的统计力学评价。
- **问题意识**：能否构建一个统一的理论框架，既能包含现有方法，又能严格导出服从玻尔兹曼分布的正则系综？
- **核心术语**：
  - Extended system method / 扩展系统方法
  - Canonical distribution / 正则分布
  - Thermostat / 恒温器（热浴）

---

## 📝 Methods
### From: [[../papers/noseUnifiedFormulationConstant1984]]
- **理论构建**：定义包含扩展自由度 $s$ 的哈密顿量，并引入对数势 $gkT \ln s$。
- **数学技巧**：利用变量缩放（Scaling）和 $\delta$ 函数积分，实现从扩展系统向物理系统的投影。
- **关键术语**：
  - Virtual variables / 虚拟变量
  - Real variables / 实变量
  - Logarithmic potential / 对数势
  - Partition function / 配分函数

## 📝 Results & Discussion
### From: [[../papers/noseUnifiedFormulationConstant1984]]
- **结论呈现**：严格证明了 ES 方法在坐标和动量空间均产生正确分布，而 HG 等标度方法存在 $O(N^{-1/2})$ 的偏差。
- **讨论要点**：
  - **参数选取**：强调了自由度参数 $g$ 的取值规则对实时采样的重要性。
  - **恒温器质量**：讨论了参数 $Q$ 如何影响体系特征频率的匹配与采样效率。
