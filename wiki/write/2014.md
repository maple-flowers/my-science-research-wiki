## 📅 年度综述
2014年的学术写作集中体现了**纳米构筑技术在微流控与光纤传感领域的深度融合**。这一年的核心贡献在于将**双光子聚合（TPP）**从单纯的静态支架制备拓展至复杂的动力学微流控组件，提出了螺旋桨叶式三维被动微混合器，成功实现了低雷诺数下的混沌对流混合。同时，在光纤传感领域，层层静电自组装（LbL）技术被用于在**本征法布里-珀罗干涉仪（IFPI）**端面构筑聚电解质纳米薄膜，确立了以干涉条纹对比度为解调量的温度不敏感湿度传感范式。这些进展标志着纳米技术正从“形貌控制”转向“功能化集成与多场解耦”。

### 核心里程碑与术语趋势
- **TPP 三维原位加工的工程化**：Liu 等人在 *Sensors and Materials* 上证明了在预封装的 PDMS 微通道内直接写入三维螺旋桨结构的可行性，通过诱导 Z 向流线打破了传统被动混合器依赖二维障碍物的局限。
- **IFPI 端面纳米涂层传感方案**：Sui 等人确立了 PAH/PSS 纳米多层膜在 IFPI 上的吸附动力学与折射率调制规律，利用条纹对比度解调消除了光源波动与温度漂移的影响。
- **术语趋势**：频繁出现“Two-photon polymerization (TPP)”、“Passive micromixer”、“Chaotic advection”、“Intrinsic Fabry-Perot interferometer (IFPI)”、“Layer-by-layer (LbL) self-assembly”、“Fringe contrast”、“Temperature-insensitive sensing”、“Hollow-core photonic crystal fiber (HCPCF)”和“Polyelectrolyte multilayer (PAH/PSS)”等术语。

## 📝 Introduction
### From: [[../papers/Unknown2014passive]]
- **研究背景 (Background)**：讨论了微尺度通道内由于层流限制导致的混合难题，以及主动混合系统对生物样品的潜在损伤。
- **问题意识**：探讨如何在微通道内设计并制造高效的三维被动混合结构，以突破二维扰动的局限并避免通道堵塞。
- **核心术语**：
  - Passive mixing / 被动混合
  - Laminar flow / 层流
  - Stream disturbance / 流线扰动
  - In-situ 3-D fabrication / 原位三维制造

### From: [[../papers/Unknown2014optical]]
- **研究背景**：回顾了光纤湿度传感器的独特优势，指出其性能高度依赖于湿敏材料的选择与构筑方式。
- **问题意识**：寻求将纳米尺度可控的聚电解质薄膜与结构紧凑的 IFPI 相结合，以实现高灵敏度与温度稳定性的统一。
- **核心术语**：
  - Relative humidity (RH) sensor / 相对湿度传感器
  - Nanocomposites / 纳米复合材料
  - Sensing mechanism / 传感机制
  - Temperature cross-sensitivity / 温度交叉敏感

## 📝 Methods
### From: [[../papers/Unknown2014passive]]
- **加工策略**：采用 532 nm 被动调 Q Nd:YAG 微片激光器配合倒置显微镜系统，在 PDMS Y 形微通道内利用 Photomer 3015 树脂原位写入三叶桨叶。
- **计算逻辑**：通过 COMSOL Multiphysics 仿真可视化三维流线，并利用像素颜色强度标准差定义混合指数（Mixing index）。
- **关键术语**：
  - Pasively Q-switched laser / 被动调 Q 激光器
  - Photoinitiator / 光引发剂
  - Mixing index (I) / 混合指数
  - Z-direction streamlines / Z 向流线

### From: [[../papers/Unknown2014optical]]
- **制备工艺**：采用层层静电自组装（LbL）技术，通过 Piranha 溶液活化表面，交替沉积 PAH 与 PSS。利用石英晶体微天平（QCM）监测膜厚增长趋势（约 4 nm/双层）。
- **解调逻辑**：建立四反射面复合 F-P 腔模型，通过反射光谱的峰-谷对比度（Fringe contrast）作为环境湿度的判据。
- **关键术语**：
  - Layer-by-layer (LbL) assembly / 层层组装
  - Quartz crystal microbalance (QCM) / 石英晶体微天平
  - Fringe contrast / 条纹对比度
  - Hollow-core photonic crystal fiber (HCPCF) / 空芯光子晶体光纤

## 📝 Results & Discussion
### From: [[../papers/Unknown2014passive]]
- **结论呈现**：螺旋桨叶式混合器在 12 μl/min 流量下混合效率超过 80%，显著优于圆柱、菱形柱及平面桨叶。
- **物理洞察**：螺旋面迫使流体获得 Z 向速度分量，通过三维拉伸折叠流体单元实现混沌对流。
- **核心术语**：
  - Chaotic advection / 混沌对流
  - Screw-shaped propeller / 螺旋桨叶
  - Streamline stretching / 流线拉伸

### From: [[../papers/Unknown2014optical]]
- **性能评估**：实现了 0.08 dB/%RH 的高灵敏度，响应时间在吸附/脱附过程中分别为 2s 和 6s；在 20–100 °C 范围内对比度波动极小。
- **物理机理**：水分子吸附导致含湿膜折射率 nf 下降，进而调制 Fresnel 反射系数，而对比度解调天然抑制了光功率与温度噪声。
- **核心术语**：
  - Fresnel reflection / 菲涅耳反射
  - Thermal stability / 热稳定性
  - Reversibility / 可逆性
