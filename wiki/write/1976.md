## 📅 年度综述
1976年标志着**倒空间数值积分标准化**的开始。这一年提出的采样方法不仅解决了晶体计算中的效率问题，还确立了现代电子结构软件中布里渊区处理的数学规范。

### 核心里程碑与术语趋势
- **Monkhorst-Pack 网格的提出**：Monkhorst 和 Pack 提出了一种基于均匀倒空间采样的通用方法，使得原本复杂的布里渊区积分能够通过离散求和精确实现。
- **数学本质的揭示**：将特殊点方法与晶体点群对称性下的“星函数”正交性联系起来，为后续更复杂的插值技术奠定了基础。
- **术语规范化**：开始广泛使用“Special points”、“K-point sampling”、“Irreducible wedge”和“Brillouin-zone integration”等术语。

## 📝 Introduction
### From: [[../papers/monkhorstSpecialPointsBrillouinzone1976]]
- **研究背景 (Background)**：指出晶体总能量和能带计算需要对周期函数进行密集的布里渊区积分，计算成本极高。
- **作者的问题意识**：如何寻找一组“最特殊”的点，使得仅通过这些点的函数值加权求和，就能代表整个区域的积分性质？
- **核心术语**：
  - Special points for Brillouin-zone integration / 布里渊区积分的特殊点
  - Reciprocal space / 倒空间
  - Computational effort / 计算代价

## 📝 Methods
### From: [[../papers/monkhorstSpecialPointsBrillouinzone1976]]
- **理论框架**：构造由整数参数 $q$ 决定的均匀坐标网格，并证明对称化基函数在这些点上的正交归一性。
- **操作逻辑**：利用点群对称性将全区积分约化为不可约楔形（Irreducible wedge）内的加权求和。
- **关键术语**：
  - Monkhorst-Pack grid / Monkhorst-Pack 网格
  - Star function / 星函数
  - Irreducible wedge / 不可约楔形
  - Point-group symmetry / 点群对称性

## 📝 Results & Discussion
### From: [[../papers/monkhorstSpecialPointsBrillouinzone1976]]
- **结论呈现**：证明了该网格具有优异的收敛性，且在偶数 $q$ 值下比奇数值更能有效利用对称性拟合函数。
- **讨论要点**：
  - **方法整合**：阐明了该方法与 Chadi-Cohen 和 Gilat-Raubenheimer 方法的内在数学联系。
  - **应用扩展**：提出了结合全局傅里叶插值与局部线性积分处理态密度（DOS）等谱性质的混合思路。
