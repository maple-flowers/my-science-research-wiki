## 📅 年度综述
2019年的学术写作见证了**关联电子体系中拓扑有序态与非常规超导的统一建模**，以及**低维铁电体从“物理发现”向“器件级集成”的成熟化演进**。这一年的核心贡献在于：理论上提出了基于 McMillan-Ginzburg-Landau 框架的统一模型，成功解释了过渡金属硫族化物（TMDs）如 1T-TiSe₂ 中电荷密度波（CDW）涨落诱导的非常规超导电性，揭示了“近公度-非公度”（NC-IC）相变在超导圆顶（SC dome）形成中的关键角色；实验上，室温铁电金属 WTe₂ 的本征极化与畴结构得到直接表征，并展示了 attojoule/bit 级的超低功耗翻转潜力。此外，光纤传感领域通过 TiO₂-SiO₂ 复合纳米膜与消逝场（Evanescent field）效应的融合，确立了全数字输出的实时湿度监测方案。

### 核心里程碑与术语趋势
- **CDW-超导竞争与耦合模型的确立**：Chen 等人在 *Nature Communications* 上构建了 39 维 saddle-point 极小化模型，预言了 SC 订单在 discommensurations（DCs）处的优先形核与渗流行为。
- **室温铁电金属的畴结构测绘**：Sharma 等人在 *Science Advances* 上利用 nanoscale PFM 首次直观展示了块材 WTe₂ 的自发铁电畴，打破了极性半金属仅能在超薄膜中切换的疑虑。
- **低维铁电体的系统性路线图**：Spaldin 与 Martin 等人在 *Nature Reviews Materials* 上综述了多铁性 domain walls 物理，确立了“Attojoule switch”作为未来微电子器件的核心愿景。
- **术语趋势**：频繁出现“Cooperative coexistence”、“CDW fluctuations”、“Discommensurations (DCs)”、“Percolation of SC order”、“McMillan-Ginzburg-Landau theory”、“Ferroelectric semimetal”、“Evanescent field sensing”、“Attojoule/bit switching”、“Skyrmions in ferroelectrics”和“Stationary contribution to permittivity”等术语。

## 📝 Introduction
### From: [[../papers/Chen2019superconductivity]]
- **研究背景 (Background)**：讨论了掺杂 TMDs 中超导性与 CDW 关联性，指出 1T-TiSe₂ 在 CDW 性质从公度向非公度转变时出现超导增强的实验事实。
- **问题意识**：探讨 CDW 涨落（表现为 domain walls 处的激发）如何通过改变局域态密度或引入低能声子来诱导 Cooper 不稳定性。
- **核心术语**：
  - Cooperative coexistence / 协同共存
  - Commensurate-incommensurate transition / 公度-非公度相变
  - Superconducting dome / 超导圆顶
  - Discommensurations (DCs) / 不公度线（域壁）

### From: [[../papers/sharmaRoomtemperatureFerroelectricSemimetal2019]]
- **研究背景**：回顾了 Anderson-Blount 预言，指出金属极化的直接观测与翻转由于自由电荷屏蔽而长期处于“elusive”状态。
- **问题意识**：在 Weyl 半金属 WTe₂ 中，探讨本征金属性与铁电性共存的证据，以及其畴结构在室温下的稳定性。
- **核心术语**：
  - Native metallicity / 本征金属性
  - Weyl semimetal / Weyl 半金属
  - Switchable spontaneous polarization / 可切换自发极化
  - Elusive state / 难以捕捉的状态

### From: [[../papers/2019optical]]
- **研究背景**：分析了现有陶瓷与聚合物湿度传感器的局限性，引出聚合物光纤（POF）在抗电磁干扰与灵活性方面的优势。
- **问题意识**：寻求一种通过剥离包层并涂覆 TiO₂-SiO₂ 复合膜的消逝场传感方案，实现高线性度与低成本的实时监控。
- **核心术语**：
  - Intensity modulation / 强度调制
  - Evanescent field / 消逝场
  - Cladding exfoliation / 包层剥离
  - Systematic errors / 系统误差

## 📝 Methods
### From: [[../papers/Chen2019superconductivity]]
- **模拟策略**：扩展了 McMillan 的 GL 理论，引入与 DCs 密度耦合的超导序参量。通过 39 维 Euler-Lagrangian 方程的数值极小化，寻找自由能绝对最小值。
- **关键术语**：
  - Harmonic expansion / 谐波扩展
  - Saddle-point equations / 鞍点方程
  - Percolation logic / 渗流逻辑
  - Lock-in energy / 锁定能

### From: [[../papers/sharmaRoomtemperatureFerroelectricSemimetal2019]]
- **表征工艺**：采用 Cleaved 获得的洁净表面，在 N₂ 惰性气氛中利用 SmartSPM 1000 进行高频（~700 kHz）PFM 测量，排除表面氧化层对极化识别的干扰。
- **关键术语**：
  - Scotch tape cleavage / 胶带机械剥离
  - Spectroscopic piezoresponse / 谱学压电响应
  - Variable-angle ellipsometry / 变角椭偏仪

### From: [[../papers/2019optical]]
- **系统集成**：详述了基于 ATMega328 的 ADC 转换流程，以及利用丙酮溶液进行光纤剥离的时间控制。
- **关键术语**：
  - Analog to Digital Converter (ADC) / 模数转换器
  - Microcontroller integration / 微控制器集成
  - Dip coating / 浸渍涂布

## 📝 Results & Discussion
### From: [[../papers/Chen2019superconductivity]]
- **统计发现**：证实了超导序首先在 DC 交点（0D）形核，随温度降低向 1D 线段和 2D 空间渗流；解释了 NbSe₂ 等材料由于 lock-in energy 较小而展现出的不同相图。
- **核心术语**：
  - Sequential percolation / 序列渗流
  - Phase diagram slice / 相图切片
  - Harmonics compatible / 谐波兼容性

### From: [[../papers/spaldinAdvancesMagnetoelectricMultiferroics2019]]
- **性能评估**：展示了超级四方相（T-like）BFO 中高达 150 μC/cm² 的极化值；提出了将“Landauer limit”（kTln2）作为多铁性开关功耗终极目标的愿景。
- **核心术语**：
  - Landauer limit / 兰道尔极限
  - Super-tetragonal phase / 超四方相
  - Hidden phases / 隐藏相

### From: [[../papers/houStrainbasedRoomtemperatureNonvolatile2019]]
- **应用前景**：评估了基于应力的 attojoule/bit 级逻辑器件的可行性，强调了有限元分析在理解电极界面应力分布中的关键作用。
- **核心术语**：
  - Attojoule/bit / 阿托焦耳每比特
  - Finite-element analysis (FEA) / 有限元分析
  - Non-volatile strain switching / 非易失应力切换
