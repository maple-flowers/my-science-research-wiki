## 📅 年度综述
2000年是**过渡态搜索与数值轨道 DFT 方法**的重要年份。这一年的学术写作不仅确立了寻找最小能量路径 (MEP) 的标准工具 CI-NEB，还系统展示了如何将局域化基函数 DFT 方法从分子体系扩展到各种类型的固体。

### 核心里程碑与术语趋势
- **CI-NEB 方法的提出**：Henkelman 等人改进了微动弹性带法，引入“爬升图像 (Climbing Image)”概念，使得一幅图像能够严格收敛到鞍点，从而精确获取活化能。
- **DMol3 固态计算框架**：Delley 公开了 DMol3 的实现细节，确立了基于数值原子轨道 (NAO) 处理周期性固体的高效流程。
- **术语趋势**：频繁出现“Climbing image”、“Saddle point”、“Minimum energy path (MEP)”、“Numerical atomic orbitals (NAO)”、“Brillouin-zone integration”和“Transferability”等术语。

## 📝 Introduction
### From: [[../papers/henkelmanClimbingImageNudged2000c]]
- **研究背景 (Background)**：讨论了过渡态理论 (TST) 在模拟稀有事件中的核心地位，以及常规 NEB 在精确定位鞍点方面的局限。
- **问题意识**：如何以零额外成本，让弹性带中的一个点能够“爬升”并锁定在势能面的最高点？
- **核心术语**：
  - Rare events / 稀有事件
  - Minimum energy path (MEP) / 最小能量路径
  - Saddle point / 鞍点（过渡态）
  - Corner-cutting / 切角问题

### From: [[../papers/Delley2000]]
- **研究背景**：回顾了早期数值轨道方法在分子体系中的成功，并指出扩展到固态时的能带连续性挑战。
- **问题意识**：能否构建一个统一框架，使数值原子轨道方法在处理金属、半导体和绝缘体固体时达到与全电子方法同等的精度？
- **核心术语**：
  - Localized basis functions / 局域化基函数
  - Periodic boundary conditions / 周期性边界条件
  - Pseudopotential transferability / 赝势可移植性

## 📝 Methods
### From: [[../papers/henkelmanClimbingImageNudged2000c]]
- **算法逻辑**：提出反转最高能图像沿切线方向的势能力，并引入基于能量的可变弹簧常数。
- **数学表述**：详述了力投影 (Nudging) 机制如何消除“下滑”与“切角”误差。
- **关键术语**：
  - Climbing image / 爬升图像
  - Force projection / 力投影
  - Variable spring constants / 可变弹簧常数

### From: [[../papers/Delley2000]]
- **数值实现**：阐述了短尾基函数截断方案、半局域赝势矩阵元构建以及 Bloechl 四面体积分修正。
- **关键术语**：
  - Numerical atomic orbitals (NAO) / 数值原子轨道
  - Semilocal pseudopotential / 半局域赝势
  - Fermi-surface curvature correction / 费米面曲率修正

## 📝 Results & Discussion
### From: [[../papers/henkelmanClimbingImageNudged2000c]]
- **精度验证**：通过 $\text{CH}_4/\text{Ir}(111)$ 解离吸附案例，展示了 CI-NEB 消除插值误差的能力。
- **讨论要点**：强调了即使在势能面复杂（存在中间极小值）的情况下，CI-NEB 依然具有鲁棒性。

### From: [[../papers/Delley2000]]
- **性能标度**：通过 $Cu, Si$ 的收敛性测试，证明了该方法对网格间距和截断半径的敏感性规律。
- **泛函评估**：比较了 LDA 与 GGA 在预测生成焓方面的系统性偏差，指出数值方法的收敛精度已优于泛函本身。
