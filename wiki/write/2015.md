## 📅 年度综述
2015年的学术写作聚焦于**纳米尺度物理机制的定量解构**与**多场耦合体系的能量竞争建模**。这一年的核心贡献体现在两个维度：在多铁性物理领域，研究者通过**二维压电力显微镜（2D PFM）**与数值反演算法，成功解码了随机取向多晶 BiFeO₃ 薄膜中的三维极化翻转路径，建立了“电荷迁移能”与“面内应力能”的竞争模型；在传感器领域，ZnO 基湿度传感器的机理被系统性地总结为水分子诱导的“施主效应”对电子耗尽层的调制规律。这些工作标志着对复杂材料体系的认知已从“现象描述”转向“多参量统计与能量平衡分析”。

### 核心里程碑与术语趋势
- **多晶薄膜三维极化反演方法的建立**：Jin 等人在 *Scientific Reports* 上提出了一种无需旋转样品即可确定随机晶粒翻转角的方法，揭示了多晶体系中 71° 翻转因势垒最低而占主导（42%）的物理事实。
- **ZnO 湿度传感机理的知识整合**：Ismail 等人系统梳理了施主效应（Donor effect）在 n 型氧化物中的作用，确立了纳米棒（电子高速通道）与纳米团簇（高比表面积）的性能标度律。
- **术语趋势**：频繁出现“Polarization switching”、“Charge migration energy”、“In-plane stress energy”、“2D Piezoresponse Force Microscopy (2D PFM)”、“Numerical inversion”、“Donor effect”、“Depletion layer”、“Adsorption-desorption hysteresis”、“Sol-gel method”和“Wide band gap semiconductor”等术语。

## 📝 Introduction
### From: [[../papers/Jin2015studying]]
- **研究背景 (Background)**：讨论了菱方相多铁性材料（如 BFO）中非 180° 畴翻转对磁电耦合的重要性。
- **问题意识**：指出多晶样品中晶粒取向的随机性导致极化矢量难以确定，亟需一种能从常规 2D PFM 信号中提取 3D 信息的分析手段。
- **核心术语**：
  - Rhombohedral ferroelectrics / 菱方相铁电体
  - Non-180° domain switching / 非 180° 畴翻转
  - Intrinsic characterization / 本征表征
  - Lateral constraints / 横向约束

### From: [[../papers/Ismail2015humidity]]
- **研究背景**：回顾了环境湿度监测在工业与医疗中的需求，强调了金属氧化物半导体（MOS）的低成本优势。
- **问题意识**：分析 ZnO 的不同纳米形貌与掺杂元素如何协同影响水分子的吸附-解吸动力学。
- **核心术语**：
  - Surface-to-volume ratio / 比表面积
  - Chemical stability / 化学稳定性
  - Response/recovery time / 响应/恢复时间
  - Hysteresis / 迟滞

## 📝 Methods
### From: [[../papers/Jin2015studying]]
- **理论建模**：基于第一性原理计算的压电张量（d₁₀₅, d₂₀₂, d₃₀₁, d₃₀₃），利用欧拉角旋转（Euler angle rotation）构建全空间响应面。
- **实验与反演**：通过 OP 与 IPx 信号的归一化匹配，遍历 7 种可能翻转路径，寻找目标函数最小值以确定翻转角。
- **关键术语**：
  - Piezoelectric tensor / 压电张量
  - Numerical inversion / 数值反演
  - Euler angles / 欧拉角
  - Global matching / 全局匹配

### From: [[../papers/Ismail2015humidity]]
- **制备与监测**：详述了溶胶-凝胶（Sol-gel）与水热生长工艺，以及利用石英晶体微天平（QCM）实时监测薄膜生长与质量吸附的方法。
- **关键术语**：
  - Hydrothermal growth / 水热生长
  - Quartz crystal microbalance (QCM) / 石英晶体微天平
  - Dielectrophoresis / 介电泳
  - Precursor / 前驱体

## 📝 Results & Discussion
### From: [[../papers/Jin2015studying]]
- **统计发现**：证实了多晶 BFO 中 71° 翻转占比最高，且发现 34% 的区域在初始极化已沿电场方向时仍发生“异常”翻转。
- **能量模型**：明确了电荷迁移能（随角度增大）与面内应力能（受约束环境影响）是决定路径选择的同等重要的竞争项。
- **核心术语**：
  - Abnormal switching / 异常翻转
  - Energy barrier / 能垒
  - Charge migration / 电荷迁移
  - In-plane stress / 面内应力

### From: [[../papers/Ismail2015humidity]]
- **结构效能**：阐明了迷宫式电极（Labyrinth electrode）因最长有效边缘而具有最高灵敏度，以及掺杂（Sn/Al）对导电性与孔隙率的权衡影响。
- **核心术语**：
  - Labyrinth electrode / 迷宫电极
  - Donor effect / 施主效应
  - Doping trade-off / 掺杂权衡
  - Depletion layer thickness / 耗尽层厚度
