## 📅 年度综述
2018年的学术写作见证了**二维半导体铁电性与拓扑物态的深度交织**，以及**单原子/团簇尺度下结构动力学演变的精确刻画**。这一年的核心贡献在于：实验上直接观测到单层 α-In₂Se₃ 在室温下的本征层内铁电性，揭示了面内/面外极化强关联（Intercorrelated）的物理机制，并利用该特性实现了可见光-电场双重操控的非易失性存储；同时，在拓扑半金属 WTe₂ 中，发现了由“电子-空穴关联”驱动的新型二维铁电性，打破了金属屏蔽电场的传统范式，确立了室温下金属极化翻转的可能性。在基础材料学领域，利用嵌入原子模型（EAM）的分子动力学模拟，系统揭示了纳米尺度钛团簇从二十面体到密堆积结构的尺寸相变规律，为增材制造（AM）中的熔滴动力学提供了微观判据。

### 核心里程碑与术语趋势
- **2D 窄带隙铁电半导体的实验确证**：Cui 等人在 *Nano Letters* 上证实了单层 α-In₂Se₃ 的 1.3 eV 窄带隙与本征铁电性，建立了“面外翻转诱导面内旋转”的耦合模型，实现了高灵敏度的光电协同存储。
- **二维铁电金属的范式突破**：Fei 等人在 *Nature* 上报道了 2-3 层 WTe₂ 的自发极化，证明了在薄膜极限下电场可穿透金属屏蔽层实现翻转，其临界温度高达 350 K 以上。
- **钛纳米团簇熔融动力学的微观建模**：Zhang 等人通过大规模 MD 模拟，确立了表面原子重排与尺寸依赖的熔融行为，揭示了小尺寸下二十面体结构的稳定性优势。
- **术语趋势**：频繁出现“Intrinsic intra-layer ferroelectricity”、“Intercorrelated IP and OOP polarization”、“Visible-light sensitivity”、“Polar metal”、“Electronic-hole correlation”、“Ferroelectric semimetal”、“Embedded-atom-method (EAM) potential”、“Icosahedron configuration”、“Size-dependent melting”和“Z-scan saturation analysis”等术语。

## 📝 Introduction
### From: [[../papers/cuiIntercorrelatedInplaneOutofplane2018a]]
- **研究背景 (Background)**：讨论了传统铁电氧化物（如 BTO, PZT）作为宽禁带绝缘体在光电子学中的局限性，引出 2D 窄禁带铁电体的需求。
- **问题意识**：探讨 α-In₂Se₃ 在单层极限下是否具备室温铁电性，及其 IP 与 OOP 极化的耦合本质。
- **核心术语**：
  - Multiaxial switching / 多轴切换
  - Visible-light sensitivity / 可见光灵敏度
  - Intra-layer ferroelectricity / 层内铁电性
  - Depolarizing field compensation / 去极化场补偿

### From: [[../papers/feiFerroelectricSwitchingTwodimensional2018a]]
- **研究背景**：回顾了 Anderson-Blount 关于极性金属的经典预言，指出传统金属中自由电子屏蔽效应与极化翻转的内在矛盾。
- **问题意识**：在层状拓扑半金属 WTe₂ 中，探讨减薄厚度是否能减弱屏蔽效应，从而实现由栅极电压调控的极化切换。
- **核心术语**：
  - Polar semimetal / 极性半金属
  - Screening effect / 屏蔽效应
  - Spontaneous electric polarization / 自发电极化
  - Robustness at room temperature / 室温稳定性

### From: [[../papers/Zhang2019a]] & [[../papers/Zhang2019b]]
- **研究背景**：指出纳米颗粒在增材制造（AM）中的重要性，强调了尺寸效应对结构转变与热学物性的显著调制。
- **问题意识**：利用原子级模拟探究从几十到几千个原子的钛团簇在加热过程中的 packing patterns 演化与熔点尺寸效应。
- **核心术语**：
  - Atomic packing patterns / 原子堆积模式
  - Structural transition / 结构转变
  - Pair distribution function / 对分布函数
  - Dismutation equilibrium / 歧化平衡

## 📝 Methods
### From: [[../papers/cuiIntercorrelatedInplaneOutofplane2018a]]
- **实验与反演**：采用 CVD 生长的高质量 In₂Se₃，利用 DART 模式下的 PFM 技术，结合 SED（扫描电子衍射）直接测绘局部 projected electric field。
- **关键术语**：
  - Dual A.C. Resonance Tracking (DART) / 双交流共振追踪
  - Scanning Electron Diffraction (SED) / 扫描电子衍射
  - Projected electric field mapping / 投影电场图谱
  - Intercorrelated polarization rotation / 互锁极化旋转

### From: [[../papers/feiFerroelectricSwitchingTwodimensional2018a]]
- **传感与诊断**：采用石墨烯作为电场传感器（Graphene sensor）间接探测 WTe₂ 的极化电荷；利用 gate electrodes 在低温与室温下演示极化迟滞。
- **关键术语**：
  - Graphene electric field sensor / 石墨烯电场传感器
  - Hysteresis in conductance / 电导迟滞
  - Carrier density modulation / 载流子浓度调制
  - Screening length / 屏蔽长度

### From: [[../papers/Scremin2018nonlinear]]
- **光学表征**：采用 Z-Scan 技术配合 100 Hz 飞秒脉冲，研究 TTF⁺ 盐在 PMMA 基质中的非线性吸收。引入基于二能级系统的稳态速率方程模型。
- **关键术语**：
  - Z-Scan technique / Z-扫描技术
  - Radical cation TTF+ / 自由基阳离子 TTF+
  - Absorption cross section (σ) / 吸收截面
  - Saturation intensity / 饱和强度

## 📝 Results & Discussion
### From: [[../papers/cuiIntercorrelatedInplaneOutofplane2018a]]
- **统计发现**：证实了 In₂Se₃ 的 IP 极化远强于 OOP 极化，解释了单畴态在单层中自发形成的稳定性；演示了具有 4 个阻态的光电协同存储器。
- **核心术语**：
  - Switchable diode effect / 可切换二极管效应
  - Four resistive memory states / 四种阻态存储
  - Anisotropic transport / 各向异性传输

### From: [[../papers/feiFerroelectricSwitchingTwodimensional2018a]]
- **物理洞察**：提出 WTe₂ 中的极化可能源自“电子-空穴关联”导致的电子云相对离子芯的移动，而非纯粹的晶格畸变，预示了极快的翻转速度。
- **核心术语**：
  - Electron-hole correlation / 电子-空穴关联
  - Non-centrosymmetric / 非中心对称
  - Fast switching dynamics / 快速切换动力学

### From: [[../papers/Zhang2019a]] & [[../papers/Zhang2019c]]
- **结论呈现**：发现小尺寸钛团簇（<3.5 nm）在熔融前存在多种结构（HCP, BCC, Ih）的共存态；确立了比热容与 Dulong-Petit 定律的偏差及其尺寸关联。
- **核心术语**：
  - Coexistence of multi-structures / 多结构共存
  - Specific heat anomaly / 比热异常
  - Critical size / 临界尺寸
