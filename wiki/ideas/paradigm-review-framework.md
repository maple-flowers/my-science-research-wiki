# 综述与领域框架构建 / Review & Field-Framework Synthesis

> 科研范式 P09：像"画领域地图"——把某个方向几十年、上百篇论文的成果收集起来，分类整理，提炼出统一框架，标出哪些路已走通、哪些路还没人走。

## 👵 太奶导读

做研究久了，一个领域会积累大量论文，新人很难入门，老手也容易"只见树木不见森林"。综述就是"画地图"：把该领域的重要成果收集起来，按材料、机制、方法分类，梳理出统一的物理/材料框架，指出共识与争议，最后给出未来方向。好的综述不只是罗列文献，而是提炼出"这个领域到底在解决什么问题、有哪些套路、下一步该往哪走"。

## 🧭 范式概述

这个范式的核心逻辑是：**以"系统梳理 + 框架提炼"为产出，为领域提供全景式认知与方向指引**。研究对象覆盖二维铁电/多铁、电荷密度波、拓扑材料、超导、二维材料家族、应变工程、忆阻器等。总体思路是：先广泛收集该领域代表性文献，按材料体系/物理机制/研究方法分类归纳，梳理关键进展与争议，提炼统一框架（分类学、相图、设计原则），最后展望未来方向与挑战。这样设计的原因在于：领域快速发展，需要有人定期"盘点"，把碎片化成果整合为可传承的知识结构。例如 [[../papers/fiebigEvolutionMultiferroics2016]] 与 [[../papers/rameshMultiferroicsProgressProspects2007]] 梳理多铁性领域全景，[[../papers/guoAdvancesTwodimensionalFerroelectric2025]] 与 [[../papers/huangTwodimensionalIn2Se3Rising2022]] 综述二维铁电与 In₂Se₃，[[../papers/chowdhuryReviewTheoreticalComputational]] 综述理论计算方法。

## 🔁 研究流程

1. **文献收集**：系统检索该领域代表性论文，建立文献库。
2. **分类归纳**：按材料体系、物理机制、研究方法分类整理。
3. **机制梳理**：提炼关键物理机制与共识/争议点。
4. **框架提炼**：构建统一分类学、相图或设计原则。
5. **展望**：指出未解决问题与未来方向。

## 🛠️ 核心方法与工具

- **文献计量/分类**：系统整理领域文献（[[../papers/fiebigEvolutionMultiferroics2016]]）。
- **机制归纳**：提炼统一物理框架（[[../papers/cheongMultiferroicsMagneticTwist2007a]]、[[../papers/spaldinAdvancesMagnetoelectricMultiferroics2019]]）。
- **材料家族梳理**：二维材料/多铁材料全景（[[../papers/vahidmohammadiWorldTwodimensionalCarbides2021]]、[[../papers/tangMultiferroicityTwodimensionalVan2025]]）。
- **方向展望**：挑战与机遇分析（[[../papers/zhangEmergingFrontiersTwodimensional2025]]、[[../papers/chenHafniumBasedFerroelectricPostMoore2026]]）。

## ✅ 适用条件

- 领域已积累足够文献，需要系统性整合。
- 存在碎片化认知，需要统一框架。
- 有明确的综述目标与读者群体。

## ⚠️ 局限与风险

- 综述时效性有限，快速发展的领域易过时。
- 分类与框架带有作者主观视角，可能遗漏或偏颇。
- 文献覆盖不全会削弱结论可信度。
- 综述本身不产生新实验/计算数据。
