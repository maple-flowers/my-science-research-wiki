研究背景:: >-
  准二维过渡金属二硫化物（TMD）在低温下同时展现出电荷密度波（CDW）和超导电性，但其微观机制，特别是金属性增强的反常行为和电子自能的线性频率依赖关系（边缘费米液体行为），无法被传统的费米面嵌套或鞍点散射理论所解释。
作者的问题意识:: >-
  作者试图构建一个统一的微观理论，以解释TMD中CDW相的起源、其反常金属行为的物理原因，以及CDW与超导态之间的内在联系，从而解决现有理论与实验之间的矛盾。
主要研究对象:: >-
  二维过渡金属二硫化物（2H-TaSe₂, 2H-TaS₂, 2H-NbSe₂, 2H-NbS₂）中的电荷密度波（CDW）相、超导相及其中的电子激发。
主要研究方法:: >-
  理论建模与解析推导。基于电子-声子耦合和费米面拓扑，构建f波对称的CDW序参量模型；利用狄拉克哈密顿量描述低能激发；通过压电耦合模型推导电子自能；运用玻色化/平均场方法处理超导配对，并进行与实验数据的对比验证。
研究意义:: >-
  为TMD中CDW和超导共存提供首个统一微观理论，解决了长期存在的实验矛盾；将CDW、狄拉克费米子、边缘费米液体和量子临界点等现代凝聚态物理概念有机融合，为理解层状过渡金属体系（包括高温超导体）的复杂相图提供了新范式。
研究结论:: >-
  TMD中的CDW态是具有六重节点对称性的f波态，其低能激发是狄拉克费米子。狄拉克电子与声子的压电耦合导致了边缘费米液体行为。超导态源于声子介导的配对，其存在量子临界点，并解释了CDW与超导转变温度的反相关关系。
对领域的贡献:: >-
  提出了一个全新的f波CDW微观理论，挑战了传统范式；首次将边缘费米液体行为与CDW相中的狄拉克电子联系起来；建立了从CDW到超导的统一理论框架，并预言了可被实验验证的狄拉克点和超导能隙。
未来研究方向提及:: >-
  使用高分辨率ARPES直接测量费米面上CDW能隙的调制和狄拉克点处的超导能隙；探索TMD与高温超导体（HTC）现象之间的深层联系，以期为理解HTC的复杂物理提供启示。
未来研究方向思考:: >-
  研究更强电子-电子关联效应对f波CDW态和狄拉克电子的影响；通过高压、掺杂等手段调控量子临界点，研究量子临界区的奇异输运行为；利用扫描隧道显微镜（STM）直接探测狄拉克费米子的态密度和朗道能级。

## CastroNeto2001charge — 二维过渡金属二硫化物中的电荷密度波、超导电性和反常金属行为

## 📄 元数据
A. H. Castro Neto，2001，Physical Review Letters 86, 4382–4385，DOI 10.1103/PhysRevLett.86.4382。
## 💡 一句话
提出 2H-TMD（TaSe₂/TaS₂/NbSe₂/NbS₂）中 CDW 是具有六重节点的 f 波序参量，CDW 相的低能激发是与声学声子压电耦合的狄拉克电子，由此统一解释了 ARPES 观测到的边缘费米液体自能、CDW 相中的良好金属性、声子介导的超导配对及其 KT 型相变与量子临界点。

  - **关键特征**：随 a/c 增大（二维性减弱、层间耦合增强），T_cdw 单调下降而 T_c 单调上升，二者呈明显反相关；TaSe₂ 的 T_c ≈ 0.1 K，已非常接近理论预言的超导量子临界点 QCP（g ≈ g_c）；加压使 c 减小、T_c 升高的实验趋势与该图像一致。

  - **图2：费米面与 f 波 CDW 能隙拓扑示意图**
  - 图 2（费米面示意图，标注狄拉克点、鞍点、节线与 f 波 CDW 能隙）笔记未附图片。
  - **图示描述**：二维布里渊区原理示意图，标出 Γ、K、M 高对称点；Γ 与 K 周围为空穴型费米面，虚线为与波矢 Q₁ 关联的节线（电子-声子耦合 g=0），实心圆为费米面与节线相交的狄拉克点，空心圆为态密度对数发散的鞍点，粗线为提议的 f 波 CDW 能隙剖面。
  - **关键特征**：CDW 能隙并非各向同性打开，而是具有六重对称性，波瓣（最大值，约 60 meV）沿 Γ-K 鞍点方向，在六个狄拉克点处降为零；Q₁ 连接不同费米面分支上的狄拉克点且嵌套良好，能形成 CDW；Q₂ 连接同一分支节点但该方向嵌套不良，故狄拉克点处不能打开能隙；节点处的无能隙低能激发即为狄拉克费米子，是 CDW 相保持良金属性的根源。
  - **结论/意义**：这是 f 波 CDW 模型的几何基础，把"动量依赖电声耦合 + 费米面拓扑 + 不完全嵌套"统一在一张图中，解释了为何 TMD 进入 CDW 后电阻率反而下降。

  - **图3：电子自能虚部 ImΣ(k_F,ω) 与 ARPES 数据对比**
  - ![图3 理论与 ARPES 测得的电子自能虚部 ImΣ(k_F,ω) 对比，ω<60 meV 呈线性，>60 meV 饱和](../../raw/figures/CastroNeto2001charge/fig_3_Y8PXIM8Z.png) -> [[../figures/electronic-bands-dos-fermi|态密度与费米面]]

  - **关键特征**：|ω| < Max|Δ_cdw| ≈ 60 meV 区间内 ImΣ 与 |ω| 呈线性关系（而非费米液体的 ω²），拟合给出 τ₀⁻¹ = 27 meV、α = 2.14、γ = 0.212；零能截距随温度线性增加 αT；当 |ω| > 60 meV 时狄拉克描述失效，ImΣ 饱和于常数 1/τ₁ ≈ 73 meV；三条理论曲线分别在对应温度上定量复现实验点。

## ✏️ 可写入 Wiki 的要点
  1. 2H-TaSe₂、2H-TaS₂、2H-NbSe₂、2H-NbS₂ 在低温下 CDW 与超导共存；CDW 是三重非公度态，波矢 Q_i = (1−δ)b_i/3（|b_i| = 4π/(√3 a)，δ≪1），TaSe₂ 还存在公度态 δ=0。
  2. [[../concepts/fermi-surface-nesting|费米面嵌套]]机制在 2D TMD 中失效：能带计算无强嵌套，CDW 相内电阻率反而下降、比热呈幂律而非指数，且低温出现超导，这些都与 1T-TaS₂ 等 1D 型绝缘 CDW 不同。
  3. Rice-Scott 鞍点散射机制也不能完全成立：更精细的能带计算显示鞍点并不如早期认为的那样接近 E_F，且实验测得 |Q_SP| > 2k_F 与 |Q_i|。
  4. ARPES 在 TMD 中测得 ImΣ(k_F,ω→0) ∝ 1/τ + b|ω|，与高温超导的[[../concepts/marginal-fermi-liquid|边缘费米液体]]行为一致，而与费米液体的 ω² 不符。
  5. 本文核心假设：CDW 能隙 Δ_cdw(k) ∝ g_λ(k,Q_i) 具有六重对称性和六个节点（f 波），瓣（最大值，约 60 meV）沿鞍点（Γ-K）方向；节点即狄拉克点，位于 Γ、K 周围空穴型费米面与 g=0 节线的交点。
  6. [[../concepts/tight-binding|紧束缚模型]]给出 g_λ(k,q) = √2/(N M ω_{λ,q}) Σ_n c_|n| e_{λ,q}·n sin(q·n/2) cos[(k+q/2)·n]，可直接证明 g(k,Q_1) 在特定节线上为零；Q_1 连接不同费米面分支上嵌套良好的节点，而 Q_2 在同分支方向上不嵌套，因此狄拉克点处不能打开能隙。
  7. 节点附近低能哈密顿量 H_D = Σ Ψ†[v_F k_⊥ σ_z + v_0 k_∥ σ_x]Ψ，色散 ε_{±} = ±√(v_F²k_⊥² + v_0²k_∥²)，即无质量[[../concepts/migdal-eliashberg-theory|各向异性]]狄拉克费米子；这是 CDW 相保持良金属性的原因。
  8. 三重 CDW 破缺晶格[[../concepts/inversion-symmetry|反演对称性]]（三子晶格结构），使[[../concepts/dirac-electrons|狄拉克电子]]通过[[../concepts/piezo-electric-coupling|压电耦合]] H_C = κ∫dr Φ(r)Σ_σ Ψ†_σΨ_σ 与声学声子耦合，自洽格林函数给出 ImΣ(k_F,ω→0) = τ₀⁻¹ + αT + γ|ω|（τ₀⁻¹ = 27 meV，α = 2.14，γ = 0.212），在 |ω| < Max|Δ_cdw| ≈ 60 meV 成立；高于该尺度狄拉克描述失效，ImΣ 饱和于 1/τ₁ ≈ 73 meV。
  9. 声子同时给出推迟吸引，配对哈密顿量 H_P = −g Σ σ_y σ_y ψ†↑ψ†↓ψ↓ψ↑（g ≈ κ²/ω_D，ω_D ≈ c_s/a），经 Bogoliubov 变换得 E_{±k} = ±√(ε_k² + |Δ_s|²)；超导相费米面在 Γ-K 方向被 CDW 能隙封闭、Γ-M 方向被超导能隙封闭。
  10. 零温超导[[../concepts/order-parameter|序参量]] |Δ_s(0,g)| = 4πv_Fv_0(1/g_c − 1/g)，仅当 g > g_c 时存在，g_c = 4π^{3/2}√(v_Fv_0)/Λ 为[[../concepts/quantum-critical-point|量子临界点]]，对应临界晶格常数 a_c；这与 BCS 无需临界耦合不同，类同 Yukawa-Higgs 手征对称性破缺。
  11. 二维相位涨落使超导转变为 KT 型，T_KT(g) = πσ_s(g)/(2m*)，σ_s ∝ |Δ_s(0,g)|²；弱层间耦合将普适类改为 3D-XY，T_c ≈ T_KT + b/ln²[T_KT/(cU_⊥)]，故 T_c随层间距 c 减小而升高；控制参数是 a/c，TaSe₂（T_c≈0.1 K）接近 QCP，加压下 T_c 升高与该图像一致。
  12. T_c < T < T*（T* = |Δ_s(0,g)|/[2 ln 2]）存在[[../concepts/pseudogap|赝能隙]]区，序参量振幅已建但相位无相干，可解释实验上 T_c 以上磁化率下降和抗磁响应；作者强调 TMD 与高温超导在反相关相图、边缘费米液体、赝能隙、条纹相等方面的相似性，但也指出 TMD 中反常金属行为源于声子（平移对称性破缺的临界模），而 HTC 中类似 QCP 的来源尚不清楚，仅靠相位涨落不足以产生边缘费米液体行为。
