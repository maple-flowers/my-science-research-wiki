## CastroNeto2001charge — 二维过渡金属二硫化物中的电荷密度波、超导电性和反常金属行为

- **元数据**：A. H. Castro Neto，2001，Physical Review Letters 86, 4382–4385，DOI 10.1103/PhysRevLett.86.4382。
- **一句话**：提出 2H-TMD（TaSe₂/TaS₂/NbSe₂/NbS₂）中 CDW 是具有六重节点的 f 波序参量，CDW 相的低能激发是与声学声子压电耦合的狄拉克电子，由此统一解释了 ARPES 观测到的边缘费米液体自能、CDW 相中的良好金属性、声子介导的超导配对及其 KT 型相变和量子临界点。

- **新概念/实体建议**：
  - `dirac-electrons`（狄拉克电子/狄拉克费米子）：在 CDW 节点附近由线性色散描述的无质量准粒子，是 CDW 相保持金属性的根源；project-7 页面已引用此概念但概念文件尚未建立。
  - `marginal-fermi-liquid`（边缘费米液体）：自能虚部 ImΣ ∝ |ω| 而非 ω² 的非费米液体唯象理论，原是为高温超导提出，本文将其推广到 TMD。
  - `electron-phonon-coupling`（电子-声子耦合）：含动量依赖矩阵元 g_λ(k,q) 的一般概念，区别于普通金属的常数近似。
  - `fermi-surface-nesting`（费米面嵌套）：CDW 经典机制，本文论证其在 2D TMD 中失效。
  - `f-wave-order-parameter`（f 波序参量）：在费米面上具有六重节点、瓣沿鞍点方向的 CDW 能隙结构，类比超导 d 波但节点数为六。
  - `piezo-electric-coupling`（压电耦合）：CDW 破缺反演对称性后，狄拉克电子与声学声子之间的标量耦合，驱动边缘费米液体行为。
  - `kosterlitz-thouless-transition`（KT 相变）：二维中超导由涡旋-反涡旋对解束缚驱动的拓扑相变，弱层间耦合将普适类变为 3D-XY。
  - `quantum-critical-point`（量子临界点）：零温下由耦合常数 g 调控的超导-金属相变点 g_c，对应临界晶格常数 a_c。
  - `pseudo-gap`（赝能隙）：T_c < T < T* 区间序参量振幅已形成但相位无相干，可解释磁化率下降和抗磁响应。
  - 实体 `TaSe2`、`TaS2`、`NbSe2`、`NbS2`（四个 2H-TMD 端元，相图主体）。
  - 实体 `ARPES`（角分辨光电子能谱，关键实验手段）。

- **可写入wiki的要点**：
  1. 2H-TaSe₂、2H-TaS₂、2H-NbSe₂、2H-NbS₂ 在低温下 CDW 与超导共存；CDW 是三重非公度态，波矢 Q_i = (1−δ)b_i/3（|b_i| = 4π/(√3 a)，δ≪1），TaSe₂ 还存在公度态 δ=0。
  2. 费米面嵌套机制在 2D TMD 中失效：能带计算无强嵌套，CDW 相内电阻率反而下降、比热呈幂律而非指数，且低温出现超导，这些都与 1T-TaS₂ 等 1D 型绝缘 CDW 不同。
  3. Rice-Scott 鞍点散射机制也不能完全成立：更精细的能带计算显示鞍点并不如早期认为的那样接近 E_F，且实验测得 |Q_SP| > 2k_F 与 |Q_i|。
  4. ARPES 在 TMD 中测得 ImΣ(k_F,ω→0) ∝ 1/τ + b|ω|，与高温超导的边缘费米液体行为一致，而与费米液体的 ω² 不符。
  5. 本文核心假设：CDW 能隙 Δ_cdw(k) ∝ g_λ(k,Q_i) 具有六重对称性和六个节点（f 波），瓣（最大值，约 60 meV）沿鞍点（Γ-K）方向；节点即狄拉克点，位于 Γ、K 周围空穴型费米面与 g=0 节线的交点。
  6. 紧束缚模型给出 g_λ(k,q) = √2/(N M ω_{λ,q}) Σ_n c_|n| e_{λ,q}·n sin(q·n/2) cos[(k+q/2)·n]，可直接证明 g(k,Q_1) 在特定节线上为零；Q_1 连接不同费米面分支上嵌套良好的节点，而 Q_2 在同分支方向上不嵌套，因此狄拉克点处不能打开能隙。
  7. 节点附近低能哈密顿量 H_D = Σ Ψ†[v_F k_⊥ σ_z + v_0 k_∥ σ_x]Ψ，色散 ε_{±} = ±√(v_F²k_⊥² + v_0²k_∥²)，即无质量各向异性狄拉克费米子；这是 CDW 相保持良金属性的原因。
  8. 三重 CDW 破缺晶格反演对称性（三子晶格结构），使狄拉克电子通过压电耦合 H_C = κ∫dr Φ(r)Σ_σ Ψ†_σΨ_σ 与声学声子耦合，自洽格林函数给出 ImΣ(k_F,ω→0) = τ₀⁻¹ + αT + γ|ω|（τ₀⁻¹ = 27 meV，α = 2.14，γ = 0.212），在 |ω| < Max|Δ_cdw| ≈ 60 meV 成立；高于该尺度狄拉克描述失效，ImΣ 饱和于 1/τ₁ ≈ 73 meV。
  9. 声子同时给出推迟吸引，配对哈密顿量 H_P = −g Σ σ_y σ_y ψ†↑ψ†↓ψ↓ψ↑（g ≈ κ²/ω_D，ω_D ≈ c_s/a），经 Bogoliubov 变换得 E_{±k} = ±√(ε_k² + |Δ_s|²)；超导相费米面在 Γ-K 方向被 CDW 能隙封闭、Γ-M 方向被超导能隙封闭。
  10. 零温超导序参量 |Δ_s(0,g)| = 4πv_Fv_0(1/g_c − 1/g)，仅当 g > g_c 时存在，g_c = 4π^{3/2}√(v_Fv_0)/Λ 为量子临界点，对应临界晶格常数 a_c；这与 BCS 无需临界耦合不同，类同 Yukawa-Higgs 手征对称性破缺。
  11. 二维相位涨落使超导转变为 KT 型，T_KT(g) = πσ_s(g)/(2m*)，σ_s ∝ |Δ_s(0,g)|²；弱层间耦合将普适类改为 3D-XY，T_c ≈ T_KT + b/ln²[T_KT/(cU_⊥)]，故 T_c 随层间距 c 减小而升高；控制参数是 a/c，TaSe₂（T_c≈0.1 K）接近 QCP，加压下 T_c 升高与该图像一致。
  12. T_c < T < T*（T* = |Δ_s(0,g)|/[2 ln 2]）存在赝能隙区，序参量振幅已建但相位无相干，可解释实验上 T_c 以上磁化率下降和抗磁响应；作者强调 TMD 与高温超导在反相关相图、边缘费米液体、赝能隙、条纹相等方面的相似性，但也指出 TMD 中反常金属行为源于声子（平移对称性破缺的临界模），而 HTC 中类似 QCP 的来源尚不清楚，仅靠相位涨落不足以产生边缘费米液体行为。
