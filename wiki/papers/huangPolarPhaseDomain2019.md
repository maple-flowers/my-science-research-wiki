领域基础知识:: >-
  拓扑量子材料、外尔半金属、拓扑绝缘体、高阶拓扑绝缘体、极性金属、自发极化、铁电性、结构相变。
研究背景:: >-
  拓扑材料研究聚焦于表面态，但表面态易受环境影响。材料内部的畴壁作为自组装界面，是探索拓扑界面态的替代方案，但相关研究极少。MoTe₂兼具第二类外尔半金属和极性金属特性，是研究畴壁拓扑态的独特平台。
作者的问题意识:: >-
  极性外尔半金属MoTe₂中是否存在极性畴和相畴？它们的微观结构是怎样的？能否被外界手段操控？这些畴壁是否承载着独特的导电界面态或拓扑态？
主要研究对象:: >-
  过渡金属二硫族化合物MoTe₂，具体研究其低温极性的Td相（外尔半金属）、高温非极性的1T'相（高阶拓扑绝缘体），以及二者之间的畴壁和Td相内部的极性畴壁。
主要研究方法:: >-
  原位低温透射电子显微镜（用于相变和畴结构成像）、高角环形暗场像扫描透射电镜（原子级结构成像）、低温扫描隧道显微镜（局域电子态密度与谱学测量）、第一性原理密度泛函理论计算（势能面和能垒计算）、群论分析。
研究意义:: >-
  首次在极性外尔半金属中实验揭示了丰富的畴壁结构，包括类超晶格的相畴壁和可操控的极性畴壁，并发现了畴壁导电的迹象，为探索拓扑-极性耦合物理和开发基于畴壁的拓扑电子器件开辟了新方向。
研究结论:: >-
  1. MoTe₂在低温下存在Td↑/Td↓极性畴壁和Td/1T'相畴壁，后者在相变中自组装成类超晶格结构。 2. 极性畴壁可在电子束辐照下通过一个以1T'相为中间态的低能垒路径进行可逆移动。 3. 扫描隧道谱学测量表明，Td/1T'相畴壁处存在增强的导电态，可能对应于高阶拓扑相预言的铰链态。
对领域的贡献:: >-
  将畴壁拓扑态的研究从理论预言和传统拓扑绝缘体拓展到了外尔半金属体系，并提供了实验证据。揭示了MoTe₂中畴壁的“多功能性”——既是结构界面，又是拓扑界面，还可被外场操控，为设计新型拓扑器件提供了材料基础与操控手段。
未来研究方向提及:: >-
  1. 深入研究极性畴壁处费米弧的重构。 2. 验证Td/1T'相畴壁的导电态是否为拓扑铰链态。 3. 探索Td/1T'类超晶格结构的宏观物性。 4. 实现基于超快光/电脉冲的拓扑开关操作。
未来研究方向思考:: >-
  1. 系统研究缺陷和掺杂对畴壁构型的调控，实现畴壁图案化。 2. 探索维度效应，研究单层或少层MoTe₂中的畴壁性质。 3. 构建微纳器件，直接测量单个畴壁的输运性质，验证其“量子导线”功能。 4. 探索磁场对手性外尔半金属中畴壁动力学的奇异影响。
