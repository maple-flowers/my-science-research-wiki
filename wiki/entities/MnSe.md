# 硒化锰 / Manganese Selenide (MnSe)

**MnSe** 在二维极限下（如双层结构）是一种典型的**滑动多铁材料 (Sliding Multiferroic)**。它通过层间滑移打破空间反演对称性，实现了垂直电极化与反铁磁序的共存与耦合，是研究磁电感生效应的理想平台 [[../papers/kaurRecentAdvancesTheoretical2025a]]。

## 1. 滑动铁电与磁性起源
- **极化起源**：双层 MnSe 属于滑动铁电体。由于层间电荷转移与轨道杂化（特别是 $Mn\text{-}dz^2$ 与 $Se\text{-}pz$ 轨道），层间滑移产生约 **$2.7\text{ pC/m}$** 的垂直自发极化。
- **磁序特征**：表现为反铁磁 (AFM) 基态。通过电场驱动的极化翻转，可以有效地调控层间的磁性相互作用。
- **电控磁矩**：实验与理论预测表明，极化翻转可感生约 **$8\text{ m\mu_B/cell}$** 的净磁矩，并实现电控塞曼劈裂。

## 2. 磁电耦合与调控
- **磁电系数**：MnSe 已被定量提取出显著的磁电系数，$\alpha_S \approx -9.8 \times 10^{-14}\text{ G\cdot cm^2/V}$。
- **应变与掺杂协同**：面内应变可显著调节其翻转能垒。此外，通过空穴掺杂（浓度约 $1.39 \times 10^{15}\text{ cm}^{-2}$），其电感生磁矩可大幅提升至 **$0.3\text{ \mu_B}$** [[../papers/kaurRecentAdvancesTheoretical2025a]]。

## 3. 主要物性参数
| 参数名称 | 数值 | 备注 |
| :--- | :--- | :--- |
| **自发极化 ($P_{out}$)** | $2.7\text{ pC/m}$ | 双层滑动极化 |
| **磁电系数 ($\alpha_S$)** | $\sim -9.8 \times 10^{-14}\text{ G\cdot cm^2/V}$ | 线性磁电效应 |
| **层间电势差** | $0.23\text{ V}$ | 极化导致的能级偏移 |
| **材料类别** | 金属卤化物/硫属化物 | 滑动多铁体 |
