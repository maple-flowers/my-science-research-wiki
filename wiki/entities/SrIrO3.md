# 铱酸锶 / Strontium Iridate (SrIrO3)

**SrIrO3** 是一种具有强自旋轨道耦合 (SOC) 的 5d 过渡金属氧化物。在二维极限下，单层 SrIrO3 展现出显著的应变诱导**相锁定 (Phase-interlocked)** 特性，可实现半导体到半金属的非易失性切换 [[../../raw/note/zhongHighthroughputExfoliationMultiferroic2025|Zhong et al. 2025]]。

## 1. 半导体-半金属相变 (Semiconductor-to-Metal Transition)

单层 SrIrO3 的电子态对晶格畸变高度敏感：
- **基态特性**：在原始 **$Pc$ 对称性** 下表现为反铁磁 (AFM) 半导体，自旋向上和向下的带隙分别为 $1.14\text{ eV}$ 和 $1.35\text{ eV}$。
- **应变触发**：施加约 **3.5%** 的 $a$ 轴压缩应变可诱导其向 **$P4bm$ (FM)** 相转变。
- **半金属性 (Half-metallicity)**：在 $P4bm$ 相下，自旋向下的带隙消失，而自旋向上的带隙加宽至 **$3.58\text{ eV}$**。此时材料表现出 **100% 的自旋极化率**。

## 2. 相锁定与自旋劈裂 (Phase-interlocked & Spin Splitting)

- **磁序翻转**：AFM 与 FM 态的切换与结构对称性（$Pc \leftrightarrow P4bm$）完全锁定，源于 IrO₅ 五面体 ($a^+a^+c^-$) 的协同重排。
- **能带调制**：随相变发生，带隙从半导体态闭合，转变为高迁移率的半金属态。
- **巨自旋劈裂**：受强 SOC 效应影响，其能带边缘的自旋劈裂能量超过 **0.2 eV**，展现出优异的自旋电子学应用潜力。

## 3. 主要物性参数

| 参数名称 | 数值 | 备注 |
| :--- | :--- | :--- |
| **磁转变温度 ($T_N$)** | $135\text{ K}$ | 反铁磁序 |
| **带隙 ($E_g, Pc$)** | $1.14\text{ eV}$ | 半导体态 |
| **带隙 ($E_g, P4bm$)** | $0\text{ / }3.58\text{ eV}$ | 半金属态 |
| **临界应变** | $a$ 轴压缩 3.5% | 驱动相变 |
| **自旋极化率** | 100% | 铁磁相下 |
