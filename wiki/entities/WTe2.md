# 二碲化钨 / Tungsten Ditelluride (WTe2)

**WTe2** 是一种独特的过渡金属硫族化合物 (TMD)，以其巨磁阻效应、拓扑 Weyl 半金属特性以及二维极限下的**铁电金属性**而著称。

## 1. 核心物理特性
### 1.1 铁电金属特性 (Ferroelectric Metal)
WTe2 是二维“铁电金属”现象的代表性材料 [[../papers/feiFerroelectricSwitchingTwodimensional2018a]]：
- **对称性破缺**：双层及多层 WTe2 采用 $T_d$ 对称性，由于层间极性堆叠打破了反演对称性。
- **电学开关**：通过垂直电场可以实现面外极化（以及关联的面内极化）的非易失性翻转，即使在材料具有良好金属性的背景下，极化态依然稳健存在。
- **极化强度**：实验测得双层 WTe2 的面外极化约 **$0.42\text{ pC/m}$** [[../papers/zhaoRealization2DMultiferroic2024]]。

### 1.2 导电畴壁与相相干
- **导电界面态**：在 WTe2 的极性畴壁或 $T_d/1T'$ 相畴壁处，存在增强的局域电导。这种导电性与材料的拓扑铰链态（Hinge states）或特定的对称性保护边界态有关 [[../papers/huangPolarPhaseDomain2019]]。
- **超导性**：单层 WTe2 在静电掺杂下表现出本征超导电性，转变温度 $T_C \sim 1\text{ K}$。

## 2. 拓扑物性
- **Weyl 半金属**：块体 WTe2 是典型的 II 类 Weyl 半金属。
- **量子自旋霍尔效应**：单层 WTe2 被证实为一种本征的二维拓扑绝缘体（单层量子自旋霍尔绝缘体），其体相绝缘而边缘导电。

## 3. 主要物性参数
| 参数名称 | 数值 | 备注 |
| :--- | :--- | :--- |
| **自发极化 ($P_{out}$)** | $0.42\text{ pC/m}$ | 双层 WTe2 实验值 |
| **矫顽电场** | $\sim 0.1\text{ V/nm}$ | 铁电金属开关阈值 |
| **磁阻效应** | 巨磁阻 (XMR) | 块体不饱和特征 |
| **材料类别** | TMDs (1T'/Td 相) | 铁电金属 & 拓扑半金属 |
