# 锰酸锶 / Strontium Manganate (SrMnO3)

**SrMnO3** 是一种经典的钙钛矿氧化物。在 2025 年的高通量剥离研究中，SrMnO3 被识别为具有高磁相变温度的潜在二维非范德华材料，并作为高 $T_N$ 材料的重要对标参考 [[../papers/zhongHighthroughputExfoliationMultiferroic2025]]。

## 1. 磁性与相变温度
SrMnO3 在块体中以 G 型反铁磁（G-AFM）序为主，其磁学性能在二维化过程中受到广泛关注：
- **磁交换相互作用**：块体 SrMnO3 的第一近邻交换相互作用强度为 **$J_1 = -8.40\text{ meV}$**，这被用作评估新型二维单层（如 [[SrOsO3|SrOsO3]]）转变温度的基准。
- **高转变温度潜力**：在筛选出的 35 种稳定 $ABO_3$ 单层中，SrMnO3 类材料通过大的 $J_1$ 和高自旋邻居数，表现出维持高温反铁磁序的能力。

## 2. 应变诱导多铁性 (Strain-Induced Multiferroicity)
研究表明，通过外延应变可以有效调控 SrMnO3 的物理特性：
- **铁电性诱导**：在特定的面内拉伸应变下，SrMnO3 可展现出显著的铁电极化，预测值达 **$55\text{ \mu C/cm}^2$**。
- **居里温度**：应变诱导的铁电相在 **$420\text{ K}$** 以上仍能保持稳定 [[../figures/crystal-structures|Wiki Figures: Crystal Structures]]。

## 3. 主要物性参数
| 参数名称 | 数值 | 备注 |
| :--- | :--- | :--- |
| **磁交换项 ($J_1$, Bulk)** | $-8.40\text{ meV}$ | 反铁磁超交换作用 |
| **铁电极化强度 ($P$)** | $55\text{ \mu C/cm}^2$ | 应变诱导 (In-plane) |
| **铁电转变温度 ($T_C$)** | $> 420\text{ K}$ | 高温稳定性 |
| **材料类别** | $ABO_3$ 氧化物 | 非范德华候选前驱体 |
