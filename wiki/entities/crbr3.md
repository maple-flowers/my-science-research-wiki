# 三溴化铬 / Chromium Tribromide (CrBr₃)

**CrBr₃** 是一种典型的二维范德华磁性材料。在单层极限下，通过特定的物理化学手段（如电荷掺杂或应变工程），CrBr₃ 可展现出本征的多铁性（Multiferroicity），即铁磁性（FM）与铁电性（FE）的共存。

## 1. 物理机制与特性 (Physical Mechanisms)

### 1.1 Jahn-Teller 畸变驱动的多铁性
- **机制**：在带电的 CrBr₃ 单层（如 $CrBr_3^{0.5-}$）中，由于 $Cr^{2.5+}$ 离子的价态不平衡，$CrBr_6$ 八面体发生不对称的 **Jahn-Teller (JT) 畸变** [[../papers/huProgressProspectsLowdimensional2019]]。
- **多铁共存**：这种不对称畸变打破了空间反演对称性，诱导出面内铁电极化（IP-FE），并与本征的铁磁序（FM）耦合。
- **锁定效应**：理论预测显示，极化方向与磁易轴（Easy Axis）平行，且极化翻转可能导致磁特性的改变。

### 1.2 范德华异质结中的应用
- 作为磁性基底，CrBr₃ 常用于构建范德华异质结，利用邻近效应调控非磁性二维材料（如石墨烯或 TMDs）的自旋输运特性 [[../papers/liuSpintronicsTwoDimensionalMaterials2020b]]。

## 2. 物理参数与特征

| 特性分类 | 物理表现 | 备注 |
| :--- | :--- | :--- |
| **磁序** | 铁磁性 (FM) | 单层 Curie 温度约 32 K |
| **铁电起源** | 不对称 JT 畸变 | 仅在带电或特定调控下出现 |
| **极化方向** | 面内 (In-plane) | 与磁易轴共线 |
| **结构** | 六角晶格 (Hexagonal) | 典型的 $BiI_3$ 型层状结构 |
