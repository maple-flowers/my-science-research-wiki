# 偏钒酸锰 / Manganese Vanadate (MnVO3)

**MnVO3** 是一种钙钛矿结构的三元氧化物。在 2025 年的高通量计算研究中，它被预测为一种可以通过剥离非范德华（non-vdW）块体获得的稳定二维单层材料，是 [[../projects/project-2-mn-multiferroics|Mn 基多铁材料研究]] 的重点候选体系 [[../papers/zhongHighthroughputExfoliationMultiferroic2025]]。

## 1. 电子与自旋特性
MnVO3 单层在二维极限下表现出优异的自旋电子学潜力：
- **巨自旋劈裂 (Giant Spin Splitting)**：其自旋劈裂能量超过 **$0.2\text{ eV}$**，在所筛选出的 35 种稳定 $ABO_3$ 单层中属于佼佼者。
- **物理起源**：这种显著的自旋劈裂源于材料中强的自旋轨道耦合 (SOC) 以及特定的对称性破缺。
- **自旋极化**：预测其能带边缘具有高水平的自旋极化，适合作为自旋注入源或逻辑器件材料。

## 2. 稳定性与剥离潜力
- **剥离可行性**：MnVO3 的剥离能预测值为 **$0.064\text{ eV/\text{\AA}}^2$**，远低于非范德华剥离的经验阈值 ($0.13\text{ eV/\text{\AA}}^2$)，与典型范德华材料（如 MoS2）处于同一量级。
- **结构稳定性**：通过第一性原理分子动力学 (AIMD) 和声子谱分析，证实了其在二维形式下的动力学和热力学稳定性，能够在 300 K 环境下保持结构完整。
- **相变势垒**：研究表明其在不同亚稳相之间存在有限的转变能垒，具有良好的动力学切换潜力。

## 3. 主要物性参数
| 参数名称 | 数值 | 备注 |
| :--- | :--- | :--- |
| **自旋劈裂能** | $> 0.2\text{ eV}$ | 显著的自旋电子学特征 |
| **剥离能 ($E_{exf}$)** | $0.064\text{ eV/\text{\AA}}^2$ | 易剥离非范德华材料 |
| **磁性序** | 磁性有序 (AFM/FM/FiM) | 属于 16 种磁性候选材料之一 |
| **材料类别** | $ABO_3$ 氧化物 | 非范德华前驱体 |
