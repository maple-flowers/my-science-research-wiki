# 过渡金属硫族化合物 / Transition Metal Dichalcogenides (TMDs)

过渡金属硫族化合物 (Transition Metal Dichalcogenides, TMDs) 是一类具有 $MX_2$ 型结构的层状范德华材料，其中 $M$ 是过渡金属原子（如 Mo, W, Nb, Ta），$X$ 是硫族原子（如 S, Se, Te）。TMDs 以其丰富的物理性质（如半导体特性、金属性、超导性、电荷密度波以及新兴的滑动铁电性）成为二维材料研究的中心。

## 👵 太奶导读

孩子，你可以把 TMDs 想象成一种超级结实的“乐高积木”。
每一片积木都是由三层原子紧紧粘在一起做成的“三明治”：中间是一层过渡金属原子（就像肉饼），上下两层是硫族原子（就像面包）。
虽然积木片内部很结实，但积木片和积木片之间只是轻轻叠在一起的，用胶带一粘就能撕开一片。这种结构让它们变得特别薄，而且每一类积木都有自己独特的超能力——有的能像镜子一样反光，有的能像水一样导电，还有的能在极低温度下产生神奇的电流波动。

## 🏗️ 结构概览

TMDs 的基本单元是一个三原子层（X-M-X）。常见的晶体多型体包括 1T（八面体配位）、2H（棱柱配位）和 3R 等。

![图：2H-NbSe₂ 的原子结构（单层与双层对照）](../../raw/figures/cossuStackingChargedensityWaves2024/fig_1_Q8LV7XLD.png)
*   **看图要点**：(a) 展示了 1H 单层和 2H 双层 NbSe₂ 的顶视图与侧视图。双层由两层单层通过 π 旋转堆叠而成。这种堆叠方式决定了体系的反演对称性及其物理性质（如 CDW 堆叠构型）。
*   **来源**：[[../papers/cossuStackingChargedensityWaves2024]] -> [[../figures/heterostructures-stacking|异质结与层间堆积]]

## 🧩 关键物性：滑动铁电性

近年来，在 TMDs（如 MoS₂）中发现了一种全新的“滑动铁电性”。通过在层间引入特定的堆叠失配（如 AB 或 BA 堆叠），可以打破空间反演对称性并产生面外极化。

![图：双层 3R-MoS₂ 中的滑动铁电翻转路径](../../raw/figures/heUltrafastSwitchingDynamics2024/fig_1_TZK5GGQL.png)
*   **关键特征**：极化翻转不是依靠原子上下跳动，而是依靠层间埃级尺度的横向滑移。这种机制避开了传统铁电体的尺寸微缩极限，能实现皮秒级的超快开关。
*   **来源**：[[../papers/heUltrafastSwitchingDynamics2024]] -> [[../figures/heterostructures-stacking|异质结与堆叠]]

## 📊 常见 TMDs 体系与性质简表

| 材料 | 常见晶相 | 物理特性 | 备注 |
| :--- | :--- | :--- | :--- |
| **MoS₂** | 2H, 3R, 1T | 半导体 / 滑动铁电 | 研究最广的 TMD 基石材料 |
| **NbSe₂** | 2H | 金属 / CDW / 超导 | 典型的强关联体系 |
| **WTe₂** | Td (1T') | 半金属 / 拓扑绝缘体 | 展现出 Weyl 半金属特性 |
| **TaS₂** | 1T, 2H | CDW / 绝缘体-金属转变 | 层间堆叠驱动 Mott 转变 |
| **VSe₂** | 1T | 顺磁 / CDW | 磁性与 CDW 耦合的候选 |
