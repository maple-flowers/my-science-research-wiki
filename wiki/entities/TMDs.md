# 过渡金属硫族化合物 / Transition Metal Dichalcogenides (TMDs)

**过渡金属硫族化合物 (TMDs)** 是一类化学式为 $MX_2$（$M$ 为过渡金属，如 Mo, W, V, Nb, Ta; $X$ 为硫族元素，如 S, Se, Te）的二维范德华材料家族。单层 $MX_2$ 通常由 $X-M-X$ 三原子层构成的“夹心”结构，具有丰富的相结构（2H, 1T, 1T', 3R）与物理特性。

## 1. 滑动铁电性 (Sliding Ferroelectricity)
TMDs 是研究二维滑动铁电性的核心体系。通过层间垂直堆叠破缺反演对称性，即使单层不具铁电性，多层体系也可产生稳定的面外极化 [[../papers/sunSlidingFerroelectricityTwodimensional2025]]：
- **3R 相堆叠**：3R-MoS₂ 和 3R-WSe₂ 是滑动铁电性的代表。其极化强度可通过微小的层间横向滑移（约原子间距）实现非易失性翻转。
- **器件应用**：利用滑动铁电性可构建铁电隧道结 (FTJ) 和非易失性突触器件，表现出优异的低能耗特性 [[../papers/sunSlidingFerroelectricityTwodimensional2025]]。

## 2. 铁电金属性与导电畴壁
TMDs 家族中存在独特的“铁电金属”态，打破了铁电性与金属性互斥的传统认知：
- **WTe2 与 MoTe2**：1T' 相的 WTe2 在二维极限下展现出本征铁电金属性。垂直电场可驱动面外极化翻转，同时保持高金属导电性 [[../papers/feiFerroelectricSwitchingTwodimensional2018a]]。
- **导电畴壁**：在 WTe2 的极性畴壁处观察到增强的局域电导，这种导电界面态与拓扑相边界密切相关 [[../papers/huangPolarPhaseDomain2019]]。

## 3. 多铁性与应变调控
- **单层多铁性**：单层 NiI₂ 被证实具有手性螺旋磁序诱导的本征二维多铁性，展现出极强的磁电耦合效应 [[../papers/songEvidenceSinglelayerVan2022]]。
- **应变工程**：TMDs 具有极高的力学柔韧性。通过柔性衬底的弯曲或机械应变，可精确调控单层的铁性序相变（如 2H 到 1T' 的转变）或极化取向 [[../papers/houStrainbasedRoomtemperatureNonvolatile2019]]。

## 4. 主要相结构与性质
| 相结构 | 特性 | 代表材料 |
| :--- | :--- | :--- |
| **2H** | 半导体，带隙 $1\text{--}2\text{ eV}$ | MoS2, WSe2 |
| **1T / 1T'** | 金属性 / 拓扑绝缘体 / 铁电金属 | WTe2, VTe2 |
| **3R** | 非中心对称堆叠，滑动铁电性 | 3R-MoS2 |
