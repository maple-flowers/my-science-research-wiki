# 氮化镓 / Gallium Nitride (GaN)

**GaN** 是第三代宽禁带半导体代表材料（带隙 ~3.4 eV），具有强压电性、高电子迁移率和高击穿电场，在铁电极化、光电器件和传感领域有广泛应用。

## 核心特性

- **极性材料**：GaN 为纤锌矿结构，沿 c 轴具有强自发极化和压电极化，是极化工程的核心材料 [[../papers/Khitrov2002internal]]。
- **铁电相关理论**：在二维铁电材料的高通量筛选中，GaN 作为 III-V 族极性半导体的参考体系 [[../papers/kaurRecentAdvancesTheoretical2025a]]。
- **宽禁带**：~3.4 eV，适用于紫外光电器件和高功率电子器件。
