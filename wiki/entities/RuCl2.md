# 二氯化钌 / Ruthenium Dichloride (RuCl2)

**RuCl₂** 是一种过渡金属二卤化物，在双层堆叠中展现出滑动铁电性，同时其块体 α-RuCl₃ 因 Kitaev 物理而闻名，是磁电耦合和自旋液体研究的前沿材料。

## 核心特性

### 滑动铁电性
- 双层 RuCl₂ 的 Berry 相垂直极化约 **0.087 pC/m**，翻转势垒低于 MoS₂ 和 InSe [[../papers/hanTunableSlidingFerroelectricity2025]]。
- 与 RuBr₂、RuI₂ 同属 RuX₂ 家族，极化强度随卤素原子序数递增（Cl < Br < I）。

### Kitaev 物理
- α-RuCl₃ 被认为是接近 Kitaev 蜂窝格子自旋液体候选材料，在磁场下可能存在长程磁序破坏。
