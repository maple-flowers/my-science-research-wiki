# 硫化锡 / Tin Sulfide (SnS)

**SnS** 是一种典型的 IV-VI 族单硫族化合物半导体。在二维极限下，它与 [[SnTe|SnTe]] 类似，展现出稳健的**面内铁电性**，是研究二维非中心对称物理的理想平台。

## 1. 二维面内铁电性
- **褶皱结构 (Puckered Structure)**：单层 SnS 具有类似黑磷的褶皱几何结构，打破了面内反演对称性。
- **铁电序稳定性**：第一性原理计算预测，单层 SnS 的铁电转变温度 $T_C$ 远高于室温。
- **极化强度**：其自发极化矢量位于面内。由于其原子级厚度，SnS 对垂直退极化场不敏感，从而克服了三维铁电体的尺寸效应极限 [[../papers/FerroelectricityMultiferroicityAtomic2023]]。

## 2. 磁电与多场耦合
- **应变调控**：SnS 的面内极化可以通过机械应变进行 90° 或 180° 的弹性旋转。
- **压电效应**：单层 SnS 展现出巨大的面内压电系数，在压电纳米发电机和柔性电子器件中具有潜在应用。

## 3. 主要物性参数
| 参数名称 | 数值 | 备注 |
| :--- | :--- | :--- |
| **转变温度 ($T_C$)** | 远高于室温 | 理论预测稳定性 |
| **极化方向** | 面内 (In-plane) | $x$ 或 $y$ 轴方向 |
| **材料类别** | IV-VI 族半导体 | 与 SnTe/GeSe 同族 |
| **对称性** | $Pmn2_1$ (铁电相) | 褶皱正交相 |
