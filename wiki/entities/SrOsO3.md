# 钌酸锶 / Strontium Osmitate (SrOsO3)

**SrOsO3** 是一种具有 5d 轨道的钙钛矿氧化物。在二维极限下，SrOsO3 单层展现出极其优异的磁学与电子学特性，是 2025 年高通量剥离研究中的明星材料之一 [[../papers/zhongHighthroughputExfoliationMultiferroic2025]]。

## 1. 巨自旋劈裂 (Giant Spin Splitting)
在二维反铁磁氧化物中，SrOsO3 单层表现出目前已知的最高自旋劈裂值：
- **价带顶 (VBM) 劈裂**：达到 **$0.606\text{ eV}$**，显著高于目前已知的二维范德华反铁磁材料。
- **物理起源**：源于极性 $P4mm$ 结构中 Os 占据两个不等价 Wyckoff 位置 (1a/1b) 导致的破缺反演对称性，以及 Os 5d 与 O 2p 轨道的强杂化（杂化率约 0.65）。
- **Rashba 自旋纹理**：在 $\Gamma$ 点附近表现出清晰的 Rashba 型自旋纹理，通过 $1\%$ 面内压缩可将其 VBM 劈裂调节至 $0.309\text{ eV}$。

## 2. 变换磁性与相变机制 (Altermagnetism & Phase Transition)
SrOsO3 单层被预测为一种典型的**变换磁性 (Altermagnetism)** 材料 [[../papers/zhongHighthroughputExfoliationMultiferroic2025]]：
- **相变路径**：$P4bm \leftrightarrow P4mm$。
- **对称性特征**：$P4bm$ 相引入了 OsO₅ 五面体绕 $c$ 轴的旋转，破缺了 $P4mm$ 中的面内自旋时间反演 $T\tau$ 与自旋翻转反演 $U\tau$。
- **应变驱动**：$1.2\%$ 的双轴拉伸应变可驱动 $P4bm$ 向 $P4mm$ 相变。该过程涉及 Os-O 面外键的增强（$-ICOHP$ 从 0.53 增至 0.91 eV），相变势垒仅为 **$9.1\text{ meV/atom}$**。

## 3. 主要物性参数
| 参数名称 | 数值 | 备注 |
| :--- | :--- | :--- |
| **Néel 温度 ($T_N$)** | $\sim 300\text{ K}$ | 室温反铁磁性 |
| **剥离能 ($E_{exf}$)** | $0.134\text{ eV/\text{\AA}}^2$ | 可剥离非范德华材料 |
| **自旋劈裂 (VBM)** | $0.606\text{ eV}$ | 二维氧化物记录值 |
| **带隙 ($E_g$)** | $0.15\text{ eV}$ | $P4mm$ 窄禁带半导体 |
| **开关能耗** | $\sim 4.4 \times 10^{-4}\text{ fJ}$ | 超低功耗器件潜力 |
