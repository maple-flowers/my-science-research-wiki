# 非本征铁电 / Improper Ferroelectricity

非本征铁电（improper ferroelectricity）指**铁电性作为"副产物"出现：极化并非直接由自身驱动的结构失稳产生，而是伴随另一有序参量（如磁有序、电荷有序、非极性畸变）的初级相变而间接出现**。典型机制包括磁致铁电（螺旋磁序破缺空间反演）、电荷有序铁电与几何铁电。非本征铁电常与磁性天然共存，是多铁材料磁电耦合的核心来源。

## 👵 太奶导读

普通（本征）铁电是"想铁电才铁电"——某原子群天生要偏心；非本征铁电则是"搭便车"——材料先发生了别的有序（比如磁矩排成螺旋、电荷排成棋盘），这个新秩序不小心把"左右对称"打破了，于是极化"顺带"出现。好处是：铁电和磁是同一个源头长出来的，天生就"磁电一家亲"，非常利于磁电耦合。

## 🧩 磁致非本征铁电

**"磁阻挫 → 复杂磁序 → 自发破缺空间反演 → 磁致电极性"** 范式是 II 型多铁的核心：逆 DM（自旋流）与交换伸缩两类微观机制给出 P ∥ e₃×Q 的方向定则（[[../papers/cheongMultiferroicsMagneticTwist2007a|Cheong 2007]]）。这类铁电的极化远小于本征铁电，但磁电耦合强度与多铁共存度远高（[[../papers/spaldinAdvancesMagnetoelectricMultiferroics2019|Spaldin 2019]]）。

## 🧩 非本征铁电的分类谱系

多铁性领域以"I 类/II 类"分类，非本征铁电（电荷有序、几何、自旋驱动）与孤对电子本征机制并列为四大机制（[[../papers/fiebigEvolutionMultiferroics2016|Fiebig 2016]]）。在二维体系中，非本征机制（如电荷有序、磁致）与层间平移（滑动铁电）共同构成铁电来源图谱（[[../papers/guanRecentProgressTwoDimensional2020|Guan 2020]]）。
