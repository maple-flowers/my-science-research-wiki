# 体光伏效应 / Bulk Photovoltaic Effect

体光伏效应（bulk photovoltaic effect, BPVE）指**在非中心对称（如铁电）晶体中，无需 p-n 结即可产生的稳态光伏电流**。其电流方向由晶体极性决定、开路电压可超过材料带隙，机制主要源于非平衡载流子的"位移电流"，是铁电体在光电转换与新型光伏器件中的重要应用基础。

## 👵 太奶导读

普通太阳能电池靠"p 型和 n 型半导体对接"（p-n 结）来把光变成电。体光伏效应则另辟蹊径：只要晶体本身不对称（比如铁电体），光照进去就能"自发"产生电流，而且电压还能超过材料本身的能隙。就像不对称的"涡轮叶片"直接把光的能量"搓"成直流电，不需要额外搭接缝。

## 🧩 体光伏效应与铁电薄膜

- **超带隙体光伏电压**：铁电薄膜通过应变工程等多元手段调控电荷、自旋、轨道与晶格自由度，可实现高于带隙的体光伏电压与畴壁导电、负电容等非常规功能（[[../papers/martinThinfilmFerroelectricMaterials2016|Martin 2016]]）。
- **铁电光伏原型**：BiFeO₃ 等钙钛矿铁电薄膜是研究体光伏效应的经典平台，其极化翻转与畴结构直接影响光伏响应（见 [[../entities/BiFeO3|BiFeO₃]]）。

## 🧩 二维铁电中的体光伏潜力

- **二维铁电光电转换**：二维铁电材料（含滑移铁电体）在光电转换领域展现出超快响应、抗疲劳等潜力，其非中心对称结构与高可调性为新型体光伏器件提供了平台（[[../papers/guoAdvancesTwodimensionalFerroelectric2025|Guo 2025]]）。
- **低维多铁整合**：通过化学功能化、异质结构建等途径将铁电性与磁性整合进低维材料，有望设计出兼具光伏与自旋调控的多功能器件（[[../papers/huProgressProspectsLowdimensional2019|Hu 2019]]）。
