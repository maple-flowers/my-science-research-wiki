# 耗尽层 / Depletion Layer

耗尽层（depletion layer）指**半导体结（如 p-n 结、肖特基结或半导体-铁电界面）中因载流子被扫出而几乎无自由载流子的区域**。耗尽层宽度与电场分布决定整流、传感与开关特性，是半导体器件物理的基础概念，在湿度传感、铁电光伏与铁电-半导体耦合器件中扮演关键角色。

## 👵 太奶导读

半导体结两边载流子"势不两立"，一相遇就在界面附近"对耗"出一片空荡荡的区域——那里的自由电子和空穴都被赶跑了，只剩下固定的带电杂质，这片"无人区"就叫耗尽层。它就像关卡间的缓冲带：带多宽，决定了电流好不好过、传感器灵不灵敏。湿度传感器正是靠水分子改变这片区域的导电性来"感知湿度"的。

## 🧩 耗尽层与湿度传感

- **ZnO 湿度传感机理**：氧化锌（ZnO）因宽禁带（3.37 eV）、高表面体积比与低成本成为理想湿度传感材料，其传感机理基于水分子吸附-解吸引起的"施主效应"导致耗尽层/电阻变化；不同纳米结构（纳米棒、纳米团簇、纳米线、纳米片）对性能有不同贡献（[[../papers/Ismail2015humidity|Ismail 2015]]）。

## 🧩 耗尽层与铁电-半导体耦合

- **铁电极化与界面电场**：BiFeO₃ 等铁电薄膜的极化状态可通过电场或机械力翻转，极化束缚电荷在界面形成类耗尽层电场，影响载流子分布与光伏响应（[[../papers/Chen2016electrical|Chen 2016]]）。
- **二维铁电多相共存**：二维铁电硫代/硒代磷酸盐（如 CuInP₂S₆）中存在能量上接近的铁电、反铁电与顺电相，可经温度、电场、离子导电性及机械应力等外部刺激相互转换，为铁电-半导体界面耗尽层工程提供了可编程极性平台（[[../papers/neumayerCompetingPolarPhases2025|Neumayer 2025]]）。
