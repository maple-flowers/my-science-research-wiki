# 陷阱深度 / Trap Depth

陷阱深度（trap depth）指**载流子（电子/空穴）被缺陷或掺杂中心捕获后，要重新释放所需跨越的能垒**。陷阱深度决定陷阱的稳定性、热释光（TL）峰位置与机械发光（ML）的储能释放行为，是长余辉发光、应力传感与辐射剂量测量材料设计的核心参数。

## 👵 太奶导读

荧光材料里有些"陷阱"会抓住被光照出来的电子，抓住的松紧程度就是"陷阱深度"——抓得太松，电子马上跑掉（余辉短）；抓得太紧，电子放不出来（不亮）。巧妙设计陷阱深度，就能做出"黑暗中还会发光"的长余辉材料和受力才发光的机械发光材料。

## 🧩 陷阱深度与机械发光

- **SrAl₂O₄:Eu 纳米磷光体**：燃烧法合成，断裂机械发光（ML）时间曲线呈双峰，365 nm 紫外光可完全恢复 ML；由热释光单一峰（196 °C）用三种方法交叉得到**陷阱深度 0.24–0.27 eV**，提出"位错运动—陷阱载流子释放—Eu²⁺ 复合"统一模型（[[../papers/KumarChoubey2011mechanoluminescence|Kumar Choubey 2011]]）。
- **压电诱导电子脱陷模型**：ZnS:Mn 与 SrAl₂O₄:Eu 弹性形变下的力致发光（EML）统一机理，定量描述 EML 强度、快慢衰减与压力依赖（[[../papers/PChandra2011mechanoluminescence|P. Chandra 2011]]）。
- **γ 辐照诱导缺陷陷阱**：Ba₃(VO₄)₂:Eu 中 γ 辐照诱发 Eu³⁺/Eu²⁺ 价态转换与 VO₄²⁻ 空穴陷阱的缺陷介导模型（[[../papers/Gulhare2021mechanoluminescence|Gulhare 2021]]）。

## 🧩 陷阱深度的测量

时间分辨装置可测量静水载荷下 ML 材料的磷光衰减曲线，含吸收因子的指数模型修正标准单指数衰减，揭示自吸收对表观衰减的影响（[[../papers/TSUJI2019phosphorescence|Tsuji 2019]]）。
