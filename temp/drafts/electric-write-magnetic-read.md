# 电写磁读 / Electric-Write Magnetic-Read

电写磁读（electric-write magnetic-read）指**以电场/电压实现对磁化状态的非易失性写入（电写），再以磁信号进行读取（磁读）**的技术范式，是磁电耦合与多铁性研究的核心应用目标。相比传统电流写入，电写具有低功耗、无焦耳热、非易失等优势，是新一代磁存储与逻辑器件的理想方案。

## 👵 太奶导读

电脑存数据，老办法是拿电流写磁——又热又费电。科学家想换个玩法：直接用电压（电场）把磁性"写"进去，写进去后断电也不丢（非易失），读的时候再按磁性读出来。这就像"用钢笔签名，不用盖章"——省力还环保。要做到这一步，材料得天生"吃电压、吐磁性"，也就是要有强磁电耦合的多铁性材料。

## 🧩 电写磁读的室温二维实现

- **室温多铁金属**：双层 CrTe₂ 是一种室温、空气稳定的二维多铁金属，其铁电性源于层间电荷转移驱动的自发极化（而非传统结构滑移），源于铁磁层与反铁磁层间的电子填充差异；该机制打破空间反演对称性并实现强磁电耦合，使电场可非易失性地翻转磁化状态——"电写"已具备器件条件（[[../papers/tianRoomtemperatureTwodimensionalMultiferroic2026|Tian 2026]]）。
- **极化翻转磁矩反转**：二维 CuCrX₂（X=S, Se）薄膜的铁电与铁磁居里温度均预测高于室温，通过极化驱动的轨道偏移与层间耦合梯度实现强磁电耦合——电场翻转电极化可导致净磁矩的 180° 反转，微观机制为自旋通道在能带结构中的交换（[[../papers/xiangTwodimensionalRoomTemperature2020|Xiang 2020]]）。

## 🧩 电写磁读的材料路径

- **低维多铁的设计原则**：二维材料是探索纳米尺度铁电与多铁的理想平台，维度降低与对称性破缺是产生铁电性的关键；铁电性可通过本征范德华层、化学修饰/外场诱导、钙钛矿薄膜"越薄越强"反常铁电态三种途径获得，通过化学功能化、异质结与第二类多铁机制可将铁电与磁性整合，设计低维多铁材料（[[../papers/huProgressProspectsLowdimensional2019|Hu 2019]]）。
