# 埃德尔斯坦效应 / Edelstein Effect

埃德尔斯坦效应（Edelstein effect）指**电流（电荷流）在无外磁场条件下诱导出非平衡自旋极化**，是自旋-轨道耦合体系的逆自旋-电荷转换过程，亦被称为电流诱导自旋极化（CISP）。该效应为"电荷写、自旋读"的自旋电子学器件提供了无需外加磁场的自旋操控手段，与铁电极化、应变调控结合可实现非易失的磁化操控。

## 👵 太奶导读

一般要摆弄磁（自旋），都得靠磁场。但有一种"歪门邪道"：在自旋-轨道耦合强的材料里，通一股电流就能凭空在边上攒出一片自旋极化——电流变成了"看不见的磁场"，这叫埃德尔斯坦效应。再配上铁电材料，用电压（电场）就能指挥磁性的开关，连磁铁都不用带。这正是新一代自旋电子器件的招牌功夫。

## 🧩 埃德尔斯坦效应与二维自旋电子学

- **二维材料的自旋注入与传输**：二维材料是自旋电子学的理想平台——通过 hBN 隧道势垒电学注入可实现近 100% 的自旋极化率，hBN 封装与悬浮技术极大提升石墨烯的自旋弛豫时间与扩散长度，异质结邻近效应是自旋操控的有效途径；实现室温二维铁磁性、解决自旋操控与传输的矛盾仍是核心挑战（[[../papers/liuSpintronicsTwoDimensionalMaterials2020b|Liu 2020]]）。

## 🧩 埃德尔斯坦效应与磁电调控

- **应变介导的磁电耦合**：在 Fe₃GaTe₂/P(VDF-TrFE) 双栅极异质结中，底栅铁电聚合物通过逆压电效应产生的应变高效传递至 Fe₃GaTe₂，改变其晶格常数，实现对磁各向异性常数 K₁ 的非易失性、可逆调控，从而改变易磁化轴方向；顶栅则主要通过铁电场效应调控载流子浓度——自旋-电荷转换所需的自旋轨道环境可由此被电压编程（[[../papers/caiFerroelectricitydrivenStrainmediatedMagnetoelectric2025|Cai 2025]]）。
- **滑动铁电的自旋轨道平台**：滑动铁电性通过层间滑移实现面外极化翻转，其 ripplocation 畴壁保证低能垒高速翻转与高热力学稳定性，并可推广至金属性与半导体性二维材料，为电流诱导自旋极化提供可重构的自旋-轨道耦合平台（[[../papers/wuSlidingFerroelectricity2D2021a|Wu 2021]]）。
