领域基础知识:: >-
  铁电体中的极化通常受限于晶格对称性，但通过调控能量竞争可使其连续旋转，形成拓扑结构。这些结构具有拓扑电荷（如涡旋为±0.5，斯格明子为±1），并涌现出与磁学拓扑结构（如斯格明子）类似但机理不同的物理现象。
研究背景:: >-
  受磁性拓扑结构研究的启发，探寻铁电材料中的极化拓扑结构成为热点。早期理论预测在纳米尺度下，去极化场和应变能可驱动极化连续旋转，形成涡旋等。随着薄膜制备和（扫描）透射电子显微镜技术的发展，多种极性拓扑结构被实验证实，但其设计原理、多场调控机制和实际应用仍面临巨大挑战。
作者的问题意识:: >-
  尽管极性拓扑结构发现众多，但如何建立普适性的设计原理以在不同材料体系中实现它们？如何通过多物理场（电、力、光、热）对它们进行精确、可逆的操控，并理解其背后的物理机制？这些拓扑结构能带来哪些独特且可用的功能，以推动下一代电子学器件的发展？当前领域从材料到器件的发展瓶颈在哪里？
主要研究对象:: >-
  铁电氧化物异质结（特别是(PbTiO₃)n/(SrTiO₃)n超晶格）与铁电氧化物纳米结构（特别是BiFeO₃纳米岛）中形成的各种**极性拓扑结构**，如通量闭合畴、涡旋、反涡旋、斯格明子、麦韧、所罗门环等。
主要研究方法:: >-
  理论层面是基于Landau理论的相场模拟，通过计算总自由能（体自由能、弹性能、静电学能、梯度能）的竞争来预测拓扑结构。实验层面主要包括：1) **制备技术**：脉冲激光沉积、自组装生长等；2) **表征技术**：原子分辨率的扫描透射电子显微镜(STEM)进行极化矢量成像，压电力显微镜(PFM)测量局域电机械响应，共振软X射线衍射(RSXD)和二次谐波产生(SHG)探测手性等。3) **调控手段**：扫描探针显微镜(SPM)施加电/力场，超快光谱施加光/热场。
研究意义:: >-
  1) **基础科学**：揭示了铁电材料中极化序参量拓扑织构的丰富物理，建立了与磁性拓扑体系的平行联系，并探索了"电Dzyaloshinskii-Moriya相互作用"等新机制。2) **技术应用**：为后摩尔时代的高性能、低功耗电子器件提供了新路径，有望在超高密度存储、逻辑运算、负电容晶体管、手性光电集成、太赫兹通信等领域实现变革性突破。
研究结论:: >-
  通过协同调控体自由能、静电学能、弹性能和梯度能，可以在多种铁电材料中成功设计并实现种类丰富的极性拓扑结构。这些拓扑结构能被电场、机械力、光场和热场等多种外场有效操控，并展现出可编程的巨电阻开关、稳态负电容、电控手性光学信号和超快太赫兹动力学等非凡功能，预示着其在下一代信息技术中的巨大应用潜力。
对领域的贡献:: >-
  本综述首次系统性地从能量竞争的角度，为极性拓扑结构的设计提出了普适性原理，将零散的研究成果整合成一个逻辑自洽的框架。它全面梳理了从材料设计、多场调控到功能应用的全链条进展，并清晰指出了领域面临的五大关键挑战，为未来研究提供了兼具深度与广度的路线图。
未来研究方向提及:: >-
  1) 将材料体系拓展至无铅、CMOS兼容及有机材料。2) 发展跨尺度、多模态的原位表征技术，厘清非电场调控机制。3) 解决器件的孤立寻址、阵列化制备和性能评估等集成难题。4) 探索多铁性材料中极化与自旋拓扑结构的共存与耦合。5) 深入研究并验证铁电体系中的"电DM相互作用"等新物理，以发现更多奇异拓扑态。
未来研究方向思考:: >-
  1) 探索拓扑织构在量子极限下的行为，研究其量子涨落和隧穿效应。2) 发展基于机器学习势函数的跨尺度模拟方法，以实现从电子结构到器件性能的精确预测。3) 研究极性拓扑结构在活性物质或生命体系（如细胞膜电位）中是否也存在类似原理，进行跨学科类比。4) 设计和制造基于极性拓扑态的人工神经形态计算单元，利用其多态和非线性动力学直接模拟突触与神经元功能。5) 探索在手性催化、对映体分离等化学过程中，利用极性拓扑结构表面的手性电场进行调控的可能性。
