领域基础知识:: >-
  铁电存储器的物理基础是基于铁电材料中可被外部电场翻转的自发极化，用于实现非易失性数据存储。传统铁电材料在纳米尺度会因退极化场效应而丧失铁电性，阻碍器件小型化。二维材料因其范德华层状结构，为解决此问题提供了新平台。
研究背景:: >-
  大数据时代对高密度、低功耗非易失性存储的需求日益迫切。传统铁电存储器（FeRAM）虽性能优异，但其核心材料在尺寸微缩至纳米级时，铁电性会因退极化场而消失，无法跟上摩尔定律和集成电路（IC）微型化的发展步伐。因此，寻找能在超薄尺度下保持稳定铁电性的新材料成为关键挑战。
作者的问题意识:: >-
  虽然二维In₂Se₃被报道具有超薄层铁电性并已用于原型器件，但学界对其不同晶相的原子结构、铁电开关的动态机制仍缺乏全面理解，且"结构-性能-器件性能"之间的关联尚未被系统梳理。本文旨在系统地回顾和总结这些关键问题，以推动该材料在工业上的实际应用。
主要研究对象:: >-
  二维硒化铟（2D In₂Se₃）材料，特别是其α相（铁电相）和β相（顺电相）家族，以及基于它们构建的多种电子器件，如铁电场效应晶体管（FeFET）、铁电半导体沟道晶体管（FeS-FET）和铁电半导体结（FSJ）。
主要研究方法:: >-
  本文为综述，总结了该领域的研究范式，包括：第一性原理计算（DFT）和分子动力学（MD）模拟用于理论预测和机制探索；化学气相沉积（CVD）、机械剥离等用于材料合成；压电力显微镜（PFM）、二次谐波（SHG）、扫描透射电子显微镜（STEM）等用于结构和性能表征；以及各类晶体管的微纳加工与电学测试。
研究意义:: >-
  2D In₂Se₃作为一种能在单层极限下保持稳定铁电性的材料，填补了高温二维铁电体的空白，有望突破传统铁电存储器的微型化瓶颈。将其应用于下一代非易失性存储和神经形态计算，对于推动信息技术硬件革命具有重要的科学意义和应用价值。
研究结论:: >-
  2D In₂Se₃是一类与传统"位移型铁电体"截然不同的"相变型铁电体"。其稳健的铁电性源于独特的"再成键"机制和面内-面外极化互锁，能有效抵抗退极化场。顺电β相具有"墨西哥帽"势能面，导致结构多样性。基于该材料的FeFET、FeS-FET等器件已在存储和神经形态计算方面展现出巨大潜力，但材料制备和器件性能仍需优化。
对领域的贡献:: >-
  1. 提出了"相变型铁电体"的新概念，深刻阐释了其抗退极化场的微观物理机制。2. 系统厘清了In₂Se₃复杂的多相结构，特别是用"墨西哥帽"势能面模型统一解释了β相的结构多样性。3. 全面梳理了从微观结构到宏观器件的"结构-性能-应用"逻辑链条，为后续研究提供了清晰的路线图。4. 明确指出了该材料在"存内计算"和"神经形态计算"等前沿领域的应用潜力。
未来研究方向提及:: >-
  1. 发展低成本、大面积、高质量的单层/少数层In₂Se₃薄膜的规模化生长技术。2. 进一步理解并优化器件性能，包括开关速度、保持力、可靠性和耐久性。3. 深入探究FeS-FET等复杂器件的工作机制，特别是澄清载流子驰豫、面内铁电性等因素的具体作用。4. 基于已知的铁电起源和化学键特性，通过高通量计算设计更多新型二维铁电材料。
未来研究方向思考:: >-
  1. 探索电场、光场等多场调控下In₂Se₃铁电畴的超快动力学，以发掘其本征的开关速度极限。2. 基于"墨西哥帽"势能面和熵壁垒理论，设计特定的热历史或电场脉冲序列，以精确控制β相中Se原子的集体行为，实现更优的翻转一致性。3. 构建全二维材料的范德华异质结铁电器件，利用二维材料干净的界面，彻底消除界面缺陷和悬挂键对器件性能的干扰。4. 研究In₂Se₃铁电性与拓扑物性、超导等其它量子序的耦合，探索其在量子信息器件中的可能性。
