领域基础知识:: >-
  电荷密度波（CDW）是低维材料中电子密度的一种周期性调制，与晶格周期可形成公度（锁定）或非公度（失配）关系。超导电性（SC）是电子形成库珀对并凝聚为零电阻态的宏观量子现象。在过渡金属二硫族化物（TMDs）中，这两种有序态常共存且竞争。
研究背景:: >-
  以1T-TiSe₂为代表为TMDs材料，在通过电子掺杂或加压抑制其公度电荷密度波（C-CDW）时，会涌现出一个超导穹顶。实验表明，超导的出现与电荷密度波（CDW）的涨落及其从公度到非公度（C-IC）转变过程中出现的近公度（NC）相密切相关，但微观机制不明。
作者的问题意识:: >-
  为理解TMDs中电荷密度波（CDW）与超导（SC）共存的实验现象，特别是超导为何出现在公度电荷密度波（C-CDW）被抑制的临界区域，作者试图构建一个统一的理论框架，探究电荷密度波（CDW）的涨落，尤其是其拓扑缺陷（错位相子），是否是诱导或增强超导电性的直接原因。
主要研究对象:: >-
  二维过渡金属二硫族化物（TMDs）的电荷密度波（CDW）相，特别是1T-TiSe₂，重点研究其公度（C）、近公度（NC）和非公度（IC）相之间的转变，以及在这些相中超导电性（SC）的涌现行为。
主要研究方法:: >-
  理论建模与数值计算。构建了一个扩展的麦克兰-金兹堡-朗道（McMillan-Ginzburg-Landau）唯象理论，包含耦合的电荷密度波（CDW）和超导（SC）自由能泛函。通过将电荷密度波（CDW）序参量进行谐波展开，将自由能极小化问题转化为多变量函数优化问题，并进行数值求解。
研究意义:: >-
  理论意义在于提出了一个普适的唯象框架，揭示了错位相子（DC）驱动的电荷密度波（CDW）涨落作为超导配对机制的新物理图像。实践意义在于成功解释了TMDs材料的实验相图，并预言了非均匀的、具有配对密度波性质的超导态，为后续实验提供了明确的验证方向。
研究结论:: >-
  电荷密度波（CDW）从公度到非公度转变的中间态——近公度相，其特征是一个由“错位相子”构成的二维网络。超导电性正是由这些错位相子的涨落所驱动，优先在错位相子（DC）处成核，形成非均匀的超导织构。模型预测，随着温度降低，超导会经历一个从0维点到1维网络再到2维整体的奇异渗流过程。
对领域的贡献:: >-
  1. 统一了电荷密度波（CDW）和超导（SC）的唯象理论，为理解两者共存提供了新范式。 2. 将超导的起源与电荷密度波（CDW）的拓扑缺陷直接联系起来，超越了传统的电荷密度波（CDW）与超导（SC）简单竞争或量子临界点涨落的图像。 3. 预言了可实验验证的新奇量子态——非均匀配对密度波态及其渗流转变。
未来研究方向提及:: >-
  1. 将理论框架推广至具有不同公度条件的其他过渡金属二硫族化物。 2. 在模型中自洽地考虑超导（SC）对电荷密度波（CDW）的反作用。 3. 在理论中引入无序效应，以研究更广泛的掺杂体系。 4. 深入研究由错位相子（DC）构成的微观超导线网格的磁通动力学与输运性质。
未来研究方向思考:: >-
  1. 可以对耦合项 `-a_1 ∑|∇ψ_j|²|Φ|²` 进行微观理论推导，例如从费米子-玻色子耦合模型出发，验证其正当性并计算 `a_1` 的数值。 2. 运用动力学平均场理论（DMFT）等非微扰方法，研究该模型在更宽参数范围内的完整相图，尤其是量子相变点的性质。 3. 设计基于STM的傅里叶变换扫描隧道谱（FT-STS）实验，直接探测超导态和电荷密度波（CDW）态的空间相位关系，以验证配对密度波图像。 4. 将该模型应用于压力调控的准一维电荷密度波（CDW）材料，探索维度效效应对错位相子（DC）和超导共存的影响。
