领域基础知识:: >-
  铁电材料、非易失性存储器、神经形态计算、互补金属氧化物半导体（CMOS）工艺、后摩尔时代电子学。
研究背景:: >-
  传统冯·诺依曼架构存在"存储墙"瓶颈，导致高能耗与低吞吐量；神经形态计算作为新兴范式，急需兼容CMOS工艺、可高密度集成的纳米突触器件。
作者的问题意识:: >-
  如何系统性地梳理并阐明铪基铁电材料（Hf-FEs）从材料物理、器件结构到神经形态系统集成的完整技术链条，以揭示其在后摩尔时代非易失性存储和新型计算中的巨大潜力与关键挑战。
主要研究对象:: >-
  掺杂氧化铪（HfO₂）基铁电材料及其构成的铁电场效应晶体管（FeFET）、铁电隧道结（FTJ）、铁电随机存取存储器（FeRAM）和铁电二极管（Fe-Diode）等器件。
主要研究方法:: >-
  本文为综述，其研究方法为系统性地回顾、归纳和评述已发表文献，总结Hf-FEs在材料掺杂、器件物理、性能表征、突触模拟和系统集成等方面的研究进展。
研究意义:: >-
  为Hf-FEs领域提供了一个从基础到应用的全面视角，明确了其作为颠覆性技术在后摩尔时代推动高密度存储、存内计算和神经形态计算发展的核心地位和实现路径，为研究者提供了宝贵的结构化指南。
研究结论:: >-
  Hf-FEs凭借其卓越的CMOS兼容性和微缩能力，克服了传统铁电材料的缺点，在非易失性存储、突触可塑性模拟、图像处理和逻辑运算中展现出巨大潜力，是实现后摩尔时代高性能、低功耗计算硬件的关键使能技术之一，但仍面临亚稳相稳定、可靠性及3D集成等挑战。
对领域的贡献:: >-
  构建了"材料-器件-物理-应用-集成"的多层次知识框架，系统地连接了Hf-FEs的微观特性和宏观系统功能，并清晰地指出了该领域当前面临的核心挑战和未来发展方向。
未来研究方向提及:: >-
  探索铁电性的原子级起源；发展低于400°C的CMOS后端工艺兼容的低温制备技术；实现Hf-FEs的三维高密度集成；通过界面与共掺杂工程解决器件可靠性问题；探索多功能融合（传感-存储-计算）和跨层次协同设计。
未来研究方向思考:: >-
  开发系统级性能退化模型以量化器件差异性的影响；建立统一理论框架以指导理性材料设计而非经验性试错；深入探索Hf-FEs与2D材料等异质集成形成的新器件物理；建立包含外围电路开销的公正、全面的系统级能效评估标准。
